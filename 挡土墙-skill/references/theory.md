# 计算原理（理正岩土·挡土墙）

来源：理正岩土《挡土墙设计软件》编制原理（DangTu.pdf）；《公路路基设计规范》JTG D30-2015；
《公路设计手册·路基》（交通部第二公路勘察设计院）。

## 1. 土压力理论

三种理论：库仑（默认）、朗肯、静止。除特别说明外**不考虑墙前被动土压力**。

### 1.1 库仑主动土压力（本 skill 内核实现）

基本假定：
1. 墙后填料为均质散粒体，仅有内摩擦、无粘聚力（按无粘性土）；
2. 墙身外移/绕墙趾外倾时，填料内出现通过**墙踵**的破裂面（按平面）；
3. 土楔受自重 G、墙背反力 Ea、破裂面反力 R 三力平衡；Ea 与墙背法线成 δ、R 与破裂面法线成 φ，均偏向阻止滑动侧；
4. 扫描若干破裂面，取使 Ea 最大的破裂面；
5. 土压力沿墙高分段线性分布，作用点为分布图形心。

数值扫描解（本内核）：

```
Ea(θ) = W(θ) · sin(θ−φ) / cos(θ−φ−α−δ)
```
- θ：破裂面与**水平**夹角；α：墙背与竖直面夹角（背坡为正，tanα=m_back）；δ：墙背摩擦角；φ：填土内摩擦角；
- W(θ)：破裂楔体自重（含换算土柱超载），自墙踵起按水平条带积分；
- 取使 Ea 最大的 θ。**破裂角（报告口径） = 90° − θ（与竖直面夹角）**；
- 分力：`Ex = Ea·cos(α+δ)`，`Ey = Ea·sin(α+δ)`；
- 作用点高度 `Ze`：土重分量取 H_calc/3、超载分量取 H_calc/2 加权。

**计算高度 H_calc**：墙背（背坡）向上延伸至与地面线的交点高度；平地面时 = 墙身高 H。
墙底截面验算假定破裂面通过**墙踵**；墙趾台阶顶截面验算假定破裂面通过**台顶前角点 A**。

### 1.2 第二破裂面

俯斜墙背（或假想墙背）坡度平缓时可能出现第二破裂面（土楔沿第二破裂面而非墙背滑动）。条件：
墙背倾角 > 第二破裂面倾角，且墙背土压力对墙背法线的倾角 ≤ 墙背摩擦角。
出现时：`E'x = Ex`，`Ey = Ex·tanα`，作用高度相同（α 为上墙墙背倾角）。

### 1.3 朗肯 / 静止

- 朗肯：`e = γ·H·Kai`（或含 c）。砂土 `Ka=tan²(45°−φ/2)`；横坡 β≠0 时用通式。只适用单段坡线、满布荷载；假想墙背取通过墙踵的竖直面。
- 静止：`p0 = K0·γ·z`。砂性土 `K0=1−sinφ'`，粘性土 `K0=0.95−sinφ'`。

### 1.4 特殊工况

- **粘性土**：换算内摩擦角法，或力多边形法（库仑 + 粘聚力 C·L 项）。裂缝深度 `hc=(2c/γ)·tan(45°+φ/2) − h0`。
- **多层土**：上层土视为下层匀布荷载，逐层求 E 后合力（层重度应接近）；出现第二破裂面时按厚度加权平均。
- **浸水**：水位以下取浮重度，另加水压力 `Eas=½·γw·hw²`（作用点距底 hw/3）；墙底浮力 `P2=λ·γw·(Hb+Hb')/2·B`。
- **地震**：库仑楔体中加水平地震力 `E=G·tanζ`；墙身水平地震荷载 `Eih=Ci·Cz·Ah·Gi·φi`（重力式 Cz=0.25，轻型 0.30）；`φi=1+hi/H(hi/H≤1)`，`φi=1.4−0.2·hi/H(hi/H>1)`。

### 1.5 车辆荷载换算土柱（公路）

换算土柱高 `h0 = ΣQ / (γ·B0·L)`，其中
`B0 = (H+a)(tgθ+tgα) − b`，`L = L0 + (H+2a)·tg30°`。
a 路肩高、b 路肩宽、L0 前后轮距+着地长、θ 破裂角。需与土压力迭代（θ 依赖荷载）。
理正可自动迭代或由用户直接给 h0、宽度。**注意**：当布置宽度很小时 h0 可能为 0（如 2.5m 矮墙）。

## 2. 重力式挡土墙验算（第七章）

### 2.1 滑动稳定 Kc
水平基底（无基础）：`Kc = f·(W+Ey) / Ex`；有基础 `Kc = f·(W+Wj+Ey)/Ex`。
倾斜基底：分解法/公式法（7.1.1-3/4），并验算地基土水平抗剪 `Kc2`（7.1.1-5/6）。
防滑凸榫：`Kc = [f·Ht·(σ2+σ3)/2 + ...]/Ex`（7.1.1-7~10），另做凸榫截面强度与自动设计。
附加集中力：被动向**减小滑移力**，非被动向增大滑移力（见 7.1.1-9/10）。

### 2.2 倾覆稳定 K0
绕墙趾：`K0 = (W·Zw + Ey·Zx) / (Ex·Zy)`；有基础加 `Wj·Zwj`；锚杆/锚桩基础另加抵抗力矩。

### 2.3 地基应力与偏心距 e
`e = B/2 − Mall/Wall`，`Wall = W + Ey`，`Mall = W·Zw + Ey·Zx − Ex·Zy`（对墙趾，顺时针正）。
要求：土质地基 e≤B/6，软岩 B/5，硬岩 B/4。
- e≤B/6：`σ1,2 = (Wall/B)(1 ± 6e/B)`；
- e>B/6：`σmax = 2·Wall / (3·Zn)`（应力重分布，不承受拉）。
承载力提高系数：趾 1.2 / 踵 1.3 / 平均 1.0（一般）；抗震 1.5/1.625/1.25。

### 2.4 墙身截面强度
验算**墙底截面**与**墙趾台阶顶截面**。
正应力：同上 e、σ 公式，`e ≤ 0.25B`（抗震 0.3B）；压应力 ≤ [σ压]，拉应力 ≤ [σ弯拉]。
剪应力：`τ = (Ex − (W+Ey)·f) / B ≤ [τ]`。公路另做**极限状态法**（强度/稳定）。

### 2.5 基础强度
钢筋混凝土底板：悬挑剪应力、主拉应力、凸榫宽度、钢筋面积 `As`。

### 2.6 整体稳定（瑞典条分法·有效应力）
`K = Mk/Mq = Σ(c'ik·li + (wi+qi)cosθi·tanφ'ik) / Σ(wi+qi)sinθi`（含筋带力 Ms、地震 Me）。

## 3. 其它墙型要点（扩展用）

| 墙型 | 主要验算 | 关键差异 |
|---|---|---|
| 衡重式 | 滑动/倾覆/地基/上下墙截面/整体 | 上下墙分别按库仑算，下墙用力多边形法；可模拟为 H=0 的重力式 |
| 半重力式 | 同重力式 + 截面配筋 | 体积小、依赖配筋 |
| 悬臂式 | 滑动/倾覆/地基/墙面板+趾板+踵板配筋/裂缝 | 假想墙背取墙踵竖直面；库仑求 l 分布图 |
| 扶壁式 | 同悬臂 + 肋板 | 整体稳定不计扶肋 |
| 加筋土式 | 内部稳定（筋带抗拉/抗拔）+ 外部稳定 | `h0` 应力分析；筋带力沿圆弧切线 |
| 桩板式/锚杆式/锚定板式 | 内力+配筋 | 不做最不利结果输出 |
| 卸荷板式/垂直预应力锚杆式/装配式悬臂/装配式扶壁 | 各自组合 | — |

安全系数（容许应力法）：滑动 1.3（地震 1.3）；倾覆 1.5（地震 1.3）；基底偏心 土 B/6、软岩 B/5、硬岩 B/4；截面偏心 0.25B（抗震 0.3B）；加筋土整体 1.25（抗震 1.1）、筋带抗拔 2.0。
