目标：生成的 Word 计算书与 `路堤挡土墙2.5m.docx` 等**结构与文字一致**。由 `scripts/gen_report.py`
按 `scripts/dantu_calc.py` 的 `report_text()` 排版输出。

## 2. 生成规则

- 每个「情况/组合」重复上述 (一)~(七)；公路增加**滑动稳定方程验算、倾覆稳定方程验算**，
  墙身截面增加**极限状态法：强度/稳定** 输出。
- 「各组合最不利结果」取所有组合中各项最不利者并标注组合号。
- 数字格式：长度/力/应力 3 位小数；比值如 Kc、K0、e 3 位小数；度 3 位小数。
- 满足写「满足: Kc = 2.075 > 1.300」，不满足写「不满足: Kc = 1.108 <= 1.300」。
- 图：计算简图（.wmf 图）可选；无图时以「原始条件:」文字代替。

## 3. 封面（可选，--cover）

多墙/正式设计计算书可加封面：项目名称 + 「挡土墙设计计算书」+ 设计阶段/计算人/校对/审核人 +
编制单位 + 证书编号 + 日期。见 `江台路东段建设项目挡土墙计算书6.29.doc`。
