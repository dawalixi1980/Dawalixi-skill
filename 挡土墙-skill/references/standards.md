# 执行标准与安全系数

## 1. 安全系数（容许应力法 / 总安全系数法）

| 项目 | 一般情况 | 地震作用 |
|---|---|---|
| 滑动稳定 Kc | 1.3 | 1.3 |
| 倾覆稳定 K0 | 1.5 | 1.3 |
| 基底合力偏心距 e | 土质地基 B/6；软岩 B/5；硬岩 B/4 | 用户定义 |
| 截面合力偏心距 e | 0.25B | 0.3B |
| 加筋土整体滑动 | 1.25 | 1.1 |
| 加筋土筋带抗拔 | 2.0 | 2.0 |

抗震强度提高系数：抗压/抗拉/抗剪均 1.5；地基承载力提高系数由用户定义（默认 1.25）。

## 2. 两种计算方法

- **容许应力法**：总安全系数法，用于通用/铁路口径。
- **极限状态法**：分项系数法，公路口径墙身截面强度/稳定采用。
  公路计算分项系数（墙身内力配筋）：重力不利 1.2 / 有利 1.0；主动土压力 1.2；静水压力 1.2；扬压力 1.2；地震力 1.0。

## 3. 荷载工况（公路）

计算荷载、验算荷载、地震时计算荷载、地震时验算荷载。
