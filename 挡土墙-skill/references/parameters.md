# 参数识别与交互指南

目标：把「一张挡土墙断面图 / 理正计算简图 / 用户描述」转成 `assets/input_template.json` 的结构化输入。
**看不清、缺项、有歧义时必须用 question 工具向用户确认，不得臆造数值。**

## 1. 从图中要读出的信息

### 1.1 墙型与执行标准
- 墙型：重力式 / 衡重式 / 半重力式 / 悬臂式 / 扶壁式 / 加筋土 / 桩板式 / 锚杆式 / 锚定板式 / 卸荷板式 / 装配式…（标题或外形判断）
- 执行标准：公路 / 通用（铁路） / 水利；无说明按**公路**并确认。

### 1.2 墙身尺寸（geometry）
| 字段 | 含义 | 图上识别 |
|---|---|---|
| H | 墙身高(m) | 墙底(墙踵底)→墙顶的竖直高度 |
| b_top | 墙顶宽(m) | 墙顶水平宽度 |
| m_face | 面坡 1:m | 墙面（外侧）坡比 |
| m_back | 背坡 1:m | 墙背（填土侧）坡比，陡→0 |
| base_slope | 墙底倾斜坡率(竖直:水平) | 基底倾斜，墙踵下降为正；不倾斜填 0 |
| step_b / step_h | 墙趾台阶 b1/h1(m) | 墙趾扩展台阶宽/高；无则 0 |
| step_follows_face | 台阶面坡是否同面坡 | 图上台阶面与墙面同坡→true；竖直→false |

> 若图给的是「面坡/背坡角度(度)」而非坡度，换算 `m = tan(角度)`。
> 若只给「顶宽/底宽/高」也可反推，但需与用户核对。

### 1.3 物理/材料（materials）
- 圬工砌体容重（浆砌片石 23、砼 24~25 kN/m³）
- 圬工之间摩擦系数（约 0.4）
- 墙身砌体容许压/弯拉/剪应力（kPa）——可查《公路设计手册·路基》P604 表3-3-21
- 材料抗压极限强度 Ra(MPa)、分项系数 γf、αs（极限状态法用）

### 1.4 墙后填土（soil）
内摩擦角 φ、粘聚力 c(kPa)、容重 γ(kN/m³)、墙背摩擦角 δ（常取 φ/2~2φ/3）。

### 1.5 地基（foundation）
- 类型：天然地基 / 钢筋混凝土底板 / 台阶式 / 换填土式 / 锚桩式
- 地基土容重 γ、内摩擦角 φ、粘聚力 c
- 修正后地基承载力特征值 fa(kPa)；提高系数 趾/踵/平均（默认 1.2/1.3/1.0）
- 墙底摩擦系数 f（土质地基 0.4~0.5）

### 1.6 坡线土柱 / 地面（surface）
- 坡面线段数及各段（水平投影 dx、竖向投影 dy）
- 每段换算土柱（距离、宽度、高度 → q=γ·h0）
- 坡面起始距离、地面横坡角度、填土对横坡面摩擦角、墙顶标高、挡墙分段长度

### 1.7 荷载
- 车辆荷载等级（城-A级、公路-I级…）→ 换算土柱
- 附加集中力：作用点 X/Y（相对墙左上角点）、P(kN/m)、作用角、是否被动土压力
- 浸水/地震：水位、地震烈度/加速度

## 2. 交互提问准则

1. 一次只问最关键、最影响结果的问题（通常：墙型、执行标准、H 与坡比、φ/γ/δ、地基承载力 fa、墙底摩擦系数 f）。
2. 图中已能确定的直接采用并在回复中列出，请用户确认。
3. 缺省值仅在**明确说明取默认**时使用（如提高系数 1.2/1.3/1.0、δ=φ/2）。
4. 单位统一：力 kN（每延米）、应力 kPa、长度 m、角度 度。

## 3. 输入 JSON 结构

见 `assets/input_template.json`。核心字段：
```
geometry{ H,b_top,m_face,m_back,base_slope,step_b,step_h,step_follows_face }
materials{ gamma_masonry,f_masonry,sigma_c,sigma_t,tau,Ra_MPa,gamma_f }
soil{ phi,c,gamma,delta }
foundation{ type,gamma,phi_found,fa,f_base,fa_toe_coef,fa_heel_coef,fa_avg_coef }
surface{ segments[{dx,dy,q}],start_x,cross_slope }
point_loads[{x,y,P,angle,passive}]
standard: "highway"|"general"
```
