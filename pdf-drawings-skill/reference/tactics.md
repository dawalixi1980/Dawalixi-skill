# 实测数据与失败模式

全部数据来自本机 `阳江市阳东区东平小城市试点创建基础设施建设项目...招标文件` 目录下的真实 PDF
（158 个文件 / 576 MB），用 `scripts/` 里的脚本跑出来的，不是估算。

## 1. 图纸幅面与文本层

| 文件 | 页数 | 幅面 | 书签 | 文本层 | 图框文字命中 |
|---|---|---|---|---|---|
| 方案5-阳春钢材产业园（初设） | 89 | A3 横 1191×842 | **98 条** | **0 字/页**（扫描件） | 1/89 |
| 方案2-海陵岛东岛园区 | 68 | A3 横 | 37 条（37/37 可信） | 574 字/页 | 53/68 |
| C04L电气工程 | 74 | A3 横 | 0 | 3 字/页（稀疏） | 11/74 |
| C03Z-1G给水工程 | 44 | A3 横 | 0 | 3 字/页 | 37/44 |
| 各投标文件 | 20–180 | 混合 | 0–128 | 0–1035 字/页 | — |

要点：
- **图纸的文本层极稀疏**（每页几十到一百多字），内容基本只有图号；图名在图框里是栅格图，抠不出来。
- **设计说明页**（一个图纸集的前若干页）文本层很厚（1000+ 字/页），这类页抽文本比转图便宜。
- 扫描件（0 字/页）只能靠视觉，但书签往往还在 —— 有书签就 0 token 拿到完整索引。

## 2. 图框（标题栏）的真实布局

实测三份图纸，位置一致：

```
页面最底部，横贯全宽的一条
  ┌──────────┬────────┬──────┬────────┬──────┬────────────┐
  │ 会签/设计 │ 制图   │ 审核 │ 工程编号 │ 图号  │ 日期        │
  └──────────┴────────┴──────┴────────┴──────┴────────────┘
              y ≈ 0.90 ~ 1.00 H
```

- `工程编号` = 205012521016
- `图号` 落在 **x ≈ 0.86 W, y ≈ 0.92 H** 的单元格里，位置跨页稳定
- 图号形态实测到的几种：
  - `C04L001-7/11` —— 册号-张号/总张数（本设计院格式）
  - `C04L002-1/2`、`C04L003-3/3`
  - `DL-01-01`、`DL-07`
  - `AD-01`、`BJ-03`、`GP-01`、`JT-02`、`ZM-01`、`LH-01`
  - `G03-1/27`、`G05-1/87`

**跨页一致性已核对**：C04L 文件文本层给 p5–p15 = `C04L001-1/11 … 11/11`，
图框栅格给 p16–p23 = `C04L002-1/2 … C04L006`，两段完全接得上。

## 3. 拼图（接触印相表）的可读下限 —— 最关键的一节

token 按「张」封顶 384，与像素无关，所以把多个图框拼成一张是省 token 的核心手段。
但拼多了会糊。实测两档：

| 配置 | 整图尺寸 | 单格 | 结果 |
|---|---|---|---|
| 74 格 / 5 列 / 每格 620px 宽 / 整条图框 | 3136×1266 | 620px | ❌ **读不清**，只能看出有图框 |
| 8 格 / 2 列 / 每格 1400px 宽 / 图号图名区 | 2818×890 | 1400px | ✅ **完全可读** |

8 格那张能读出的内容：`工程编号 205012521016`、`图号 C04L002-1/2`、`专业 电气`、
`阶段 初设`、`日期 2025.11`，连手写签名都能辨认。

**结论**：`--cols 2 --sheet-width 1400` 是安全下限。要拼更多就先缩小裁剪区域
（只裁图号图名那块 `--box titleblock`），别缩像素。

成本对比（C04L 74 页）：
- 逐张渲染图框：74 × 384 = **28,416 token**
- 拼图 8 格/张：10 张 = **3,840 token**
- 文本层能读到的部分：**0 token**

## 5. 失败模式（踩过的坑）

1. **Read 一个 .pdf 直接失败** —— 本机模型不支持 pdf 输入，必须转图。
2. **图号正则贪心截断**：`C04L001-1/11` 被截成 `L001-1/11`（丢了册号前缀 `C04`）。
   修法：模式写成 `[A-Za-z][A-Za-z0-9]{0,7}[-－]\d{1,3}\s*/\s*\d{1,3}`，不要用 `[A-Za-z]{1,4}\d{1,4}`。
3. **对页面底部整条带做正则会捞到正文**：图纸底带里混着 `5.3.3、不同回路…` 这类设计说明。
   修法：图号先按「右下单元格坐标」取，再按「图号」标签取，最后才退化成整带正则。
4. **图名不能靠正则猜**：底带里正则出的「图名」全是正文垃圾（实测出现过 `具有表`、
   `接地引入线分组接地示意图`）。修法：图名只认显式「图名」标签，拿不到就是拿不到，
   交给 `--box auto` 渲染读。
5. **目录页分支会抢逐页图框的活**：早期版本让图纸目录页优先，结果产出 38 条垃圾条目、
   页码全是目录页。修法：优先级改为 书签 → 逐页图框 → 目录页；且目录页只用于**补图名**。
6. **裸的「名称」「编号」会误命中**「工程名称」「设计号」。修法：标签只用「图号/图名/图纸编号/图纸名称」。
7. **书签页码可能是 0 或大量重复**：CAD 导出的书签常见。probe/index 会报
   `toc_pages_reliable`，不可信时按 `seq` 顺序逐张渲染图框确认。
8. **整页渲染文件过大**：A3 130 DPI 整页 PNG 实测 6.5 MB。整页通读建议 `--dpi 130` 或
   `--format jpg`；裁剪局部才用高 DPI。
9. **`get_drawings()` 很慢**：复杂 CAD 页要几秒。probe 默认不算，只有 `--deep` 才统计。

## 6. 命令速查

```bash
S=<skill>/scripts
python $S/probe.py  a.pdf                       # 体检 + 成本预估
python $S/index.py  a.pdf -o idx.json           # 0 token 建索引
python $S/render.py a.pdf --boxes               # 列出区域预设
python $S/render.py a.pdf --page 52 --box auto --dpi 200        # 单页图框（自动定位）
python $S/render.py a.pdf --page 52 --box full --dpi 130        # 整页通读
python $S/render.py a.pdf --page 52 --crop 0.05,0.10,0.45,0.40 --dpi 400   # 局部复核
python $S/render.py a.pdf --sheet --box auto --pages 16-23 \
       --cols 2 --sheet-width 1400 --dpi 150                     # 拼图（省 token 关键）
```
渲染结果缓存于 `<pdf目录>/.pdfdraw/<指纹>/`，同参数不重渲染。
