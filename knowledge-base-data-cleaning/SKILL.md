# 知识库数据清洗

## 定位

**中介技能**——不直接面向最终输出，而是作为投标写作流水线的前置处理环节。

```
IMA知识库原始文档 → 本技能清洗 → 泛化模板 → 写作引擎填充真实数据
```

## 触发词

"清洗数据"、"数据脱敏"、"模板泛化"、"知识库清洗"、"去项目化"

## 输入

- IMA 知识库中检索到的 Markdown 文档
- 任意包含投标项目具体信息的文本

## 输出

- 清洗后的泛化模板文档（.md），保留到 `输出/清洗模板/`
- 可选的：清洗前后对照报告

### 大类五：保留不洗的内容

以下内容**绝对不洗**，原文保留：

| 保留类别 | 说明 |
|----------|------|
| 技术规范标准编号 | 如 CJJ 37-2012、GB 50014-2021 |
| 技术参数范围 | 如 "压实度不小于98%"、"纵坡控制在 0.3%至6%" |
| 设计原则与理念 | 如 "安全耐久、绿色低碳、智慧高效" |
| 工艺流程描述 | 如 "换填法是将基础底面以下..." |
| 章节编号与标题 | 如 "第一章"、"一、"、"1.1"（可选洗或不洗） |
| 表格结构 | 完整保留表格框架 |
| 数学公式 | 完整保留 |
| 通用专业术语 | 如 "水泥搅拌桩"、"塑料排水板"、"BIM技术" |

## 清洗脚本

使用 Python 批量清洗 Markdown 文件：

```bash
python3 -c "
import re, sys
content = sys.stdin.read()

# === 清洗规则集（按顺序执行） ===

# 1. 完整长项目名称（含后续"一"、"一期"等续文）
content = re.sub(
    r'(广东省|广西|湖南|湖北|江苏|浙江|四川|山东|河南)[\u4e00-\u9fa5]{8,80}(工程|项目)(一[\u4e00-\u9fa5]{2,20})?',
    '某某省某某市某某工程', content)

# 2. 省名 → 某某省
content = re.sub(r'(广东省|广西壮族自治区|湖南省|湖北省)', '某某省', content)

# 3. 市名（带后缀匹配） → 某某市
content = re.sub(r'(阳江市|茂名市|广州市|深圳市|珠海市|东莞市|佛山市)', '某某市', content)

# 4. 区县/试验区名 → 某某区
content = re.sub(r'海陵岛经济开发试验区|滨海新区|某某新区', '某某区', content)
content = re.sub(r'[一-龥]{2,4}(开发区|试验区|新区|片区)', '某某区', content)

# 5. 道路名（优先匹配已知路名，避免误伤技术术语如"水泥砼路面"）
# 已知路名精确匹配
content = re.sub(r'(吉港大道|东来路|达港路|海陵大堤|漠阳江|那龙河|漠西河|双捷运河|中心洲干渠)', '某某路', content)
# 通用路名：仅匹配以大道/路结尾且前后为标点/空格/行首尾的2-4字路名
content = re.sub(r'(?<=[。，、\s])[一-龥]{2,4}(大道|路)(?=[。，、\s])', '某某路', content)
content = re.sub(r'^[一-龥]{2,4}(大道|路)(?=[。，、\s])', '某某路', content)

# 6. 行政机构 → 某某局
content = re.sub(r'阳江市[一-龥]{2,4}局|广东省[一-龥]{2,6}局|某某局', '某某市某某局', content)

# 7. 公司/机构名 → 某某公司
content = re.sub(r'[一-龥]{4,20}(有限公司|科技有限公司|管理有限公司|工程有限公司|设计院|地质大队)', '某某公司', content)

# 8. 金额（万元）→ ×××万元
content = re.sub(r'\d{2,8}\.\d{1,2}\s*万元', '×××万元', content)
content = re.sub(r'\d{2,8}\s*万元', '×××万元', content)

# 9. 面积（亩/平方公里）
content = re.sub(r'\d{2,6}\.\d?\s*亩', '×××亩', content)
content = re.sub(r'\d{2,5}\.\d?\s*平方公里', '×××平方公里', content)

# 10. 长度（m/米/公里/km）
content = re.sub(r'\d{2,6}\.\d{1,3}\s*[mM米]', '×××m', content)
content = re.sub(r'\d{1,3}\.\d{1,3}\s*(公里|km)', '×××km', content)

# 11. 道路宽度（支持"宽度为22米"和"宽度22米"两种写法）
content = re.sub(r'(红线宽度|路幅宽度|宽度)\s*为?\s*\d{1,3}\s*(米|m)', r'\1为××米', content)

# 12. 设计速度
content = re.sub(r'(设计速度|车速)\s*为?\s*\d{2,4}\s*km/h', r'\1为××km/h', content)

# 13. 天数
content = re.sub(r'\d{1,3}\s*(个)?日历天', '××日历天', content)

# 14. 百分比
content = re.sub(r'\d{1,3}\.\d{1,2}\s*[%％]', '××%', content)

# 15. 招标编号
content = re.sub(r'市住建\(\d{4}\)第\d+号', '市住建(××××)第××号', content)
content = re.sub(r'[A-Z]+\d{2,}[A-Z]*-\d{4}-\d+-\d+-\d+-\d+', '××××-×××××-××-××-×××××', content)

# 16. 经纬度
content = re.sub(r'\d{2,3}°\d{1,2}[′\']\s*至\s*\d{2,3}°\d{1,2}[′\']', '××°××′至××°××′', content)

# 17. 自称 → 中性化
content = re.sub(r'我院', '我方', content)
content = re.sub(r'本院', '我方', content)

# 18. 特定园区/岛屿名（但保留泛称）
content = re.sub(r'(海陵岛|海陵试验区|海岛)', '某某园区', content)

# 19. 甲方自称 → 中性化
content = re.sub(r'阳江市|茂名市', '某某市', content)

# 20. 清理残留多余空格占位符
content = re.sub(r'某某\s+省', '某某省', content)
content = re.sub(r'某某\s+市', '某某市', content)

sys.stdout.write(content)
" < 输入文件.md > 清洗后_模板.md
```

## 工作流程

### 步骤一：获取原始文档

从 IMA 知识库检索或用户提供的路径读取目标 Markdown 文档。如果是 PDF/DOCX 格式，先用 `markitdown-skill` 转换为 Markdown。

### 步骤二：执行清洗

运行上述 Python 清洗脚本，将输入文件管道清洗后输出到 `输出/清洗模板/` 目录。

```bash
mkdir -p "输出/清洗模板"
python3 -c "<清洗脚本>" < 原始文档.md > "输出/清洗模板/模板_泛化.md"
```

### 步骤三：质量检查

对清洗结果做三项检查：
1. 搜索残留的地名关键字确认已清除（用 grep 搜索 `阳江|茂名|海陵|达港` 等）
2. 确认技术规范编号和标准名称完好（用 grep 搜索 `CJJ|GB |JTJ|JTG`）
3. 确认表格结构无破损

### 步骤四：交付

将清洗后的泛化模板交付给写作引擎。如果发现有残留需要进一步清洗，补充规则后重新执行。

## 作为中介技能的调用方式

本技能不生成最终文档，而是作为流水线中间环节：

```
智博渊（知识引擎）
  → 检索 IMA 知识库获取原始文档
  → 调用本技能清洗脱敏
  → 交付泛化模板给 文成笔（写作引擎）
  → 文成笔以模板为骨架，填入真实项目数据
```
