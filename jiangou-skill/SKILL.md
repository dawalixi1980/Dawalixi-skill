# jiangou-skill — 从主观问题长出一张知识网

> 只做一件事：**你说想学什么 → 从现象提问 → 用已知去顶 → 边建边拆 → 织成网 → 体检补漏。**
> 与 `question-skill` 的区别：它是**被动答疑**；渐构是**主动织网**。

## 相关 skill 分工

| Skill | 职责 |
|---|---|
| **jiangou-skill（本件）** | 主动织网：主观问题 → 知识网络（`[[双向链接]]`） |
| `question-skill` | 被动答疑（问答归档） |
| `math-render` | 公式 / 函数图 → PNG |
| `lexiang-search` / `lexiang-setup` | 乐享知识库检索与连接 |
| `learn-skill` | 系统建库骨架（可选） |

## 两条铁律（来自《变构模型》）

> [!important] ① 起点允许错，终点必须纠
> 从你**已有的理解**（哪怕错、片面）出发是**必须的**；但每一步都要有「**被现象顶回去 → 解构纠错**」。
> 否则网长在错误的地基上，**越长越歪**。

> [!important] ② 主观主干 ＋ 权威体检
> 你**主观织网**；用「**主观主干 ＋ 教材目录**」两层骨架做**查漏体检**，解决"全不全"的担忧。

## 渐构八拍（核心循环）

| 拍 | 做什么 | 产出 |
|:--:|---|---|
| ① **起兴** | 从「现象」提出一个主观问题 | 问题页开头 |
| ② **探界** | 用已会的概念去顶它，探清边界 | 边界记录 |
| ③ **立骨** | 先立一层薄骨架（主观主干） | 骨架页 |
| ④ **建模** | 用大白话说清「它研究什么 / 为何存在」 | 通俗解释 |
| ⑤ **追问** | 为什么需要它？怎么会想到？形式为何如此？ | 追问段 |
| ⑥ **解构** | 用现象 / 事实顶旧理解，错的当场拆 | 纠错记录 |
| ⑦ **织网** | 新知识点挂到旧知识点（`[[双向链接]]`） | 知识网络 |
| ⑧ **体检** | 用骨架对照查漏 → 标缺口 → 复习复述 | 缺口 / 复习 |

> 详细步骤见 [references/workflow.md](references/workflow.md)。

## 结构与产物

```
<项目>/
├── 骨架.md          # 全局骨架（主观主干 ＋ 教材目录对照）
├── 问题/<问题>.md    # 问题层：现象 → 主观理解 → 探界 → 【长出 N 个知识点】
├── 知识点/<知识点>.md # 知识点仓库：详细介绍 ＋ 教学；互相 [[双向链接]] 印证
├── 账本.md          # 缺口 / 断链 / 待证
└── library/books/   # 书
```

- 文件分文件夹存放，但**导航完全靠 `[[双向链接]]`，不按目录结构**。
- **每个问题页要记**：这个问题**长出了多少个知识点**（数量 ＋ 链接）。

## 反模式 & 自查

| 反模式 | 自查 |
|---|---|
| **只建不拆**（旧概念不纠） | [ ] 有"解构 / 纠错"记录 |
| 不探边界（问题够不着，硬灌） | [ ] 先探过边界 |
| 只堆不连（无双向链接） | [ ] 问题 ⇄ 知识点、知识点 ⇄ 知识点 都有 `[[ ]]` |
| 不体检（不知漏没漏） | [ ] 用骨架查过漏 |
| 节点真假不分 | [ ] 标了 `主观 / 已验证 / 待证` |
