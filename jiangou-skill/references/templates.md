# 模板（问题页 / 知识点页 / 骨架页）

## 一、问题页 `问题/<问题>.md`

```markdown
# 问题：<现象 / 疑问>

- **现象**：<触发这个问题的现象 / 场景>
- **我原本的理解**（主观，可能错）：<...>
- **探到的边界**：会 <...>；不会 <...>
- **追问**：为什么需要它？怎么会想到？形式为何如此？
- **长出 N 个知识点**：N=3 → [[知识点A]] ｜ [[知识点B]] ｜ [[知识点C]]
- **待证**：<...>
```

## 二、知识点页 `知识点/<知识点>.md`

```markdown
# <知识点>

> 状态：主观 / 已验证 / 待证

- **一句话（研究什么）**：<...>
- **通俗建模**：<大白话>
- **详细教学**：<...>
- **公式 / 图**：![<图注>](./img/<名>.png)
- **相互印证**：[[相关知识点1]] ⇄ [[相关知识点2]]
- **出处 / 佐证**：《...》 <乐享链接>（检索日期 YYYY-MM-DD）
- **来自问题**：[[问题：...]]
```

## 三、骨架页 `骨架.md`

```markdown
# 骨架

## 主观主干（我自己的核心问题 / 概念）
[[...]] → [[...]] → [[...]]

## 教材目录对照（体检用）
| 章 | 我有没有 |
|:--:|:--:|
| ... | ✅ / ⬜ |
```

## 四、账本页 `账本.md`

```markdown
# 账本

| 日期 | 缺口 / 断链 / 待证 | 关联 | 状态 |
|---|---|---|---|
| | | | |
```
