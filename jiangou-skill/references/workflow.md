# 渐构八拍详解

> 每一轮织网 = **起兴 → 探界 → 立骨 → 建模 → 追问 → 解构 → 织网 → 体检**。

## ① 起兴（从现象提问题）

- **从"现象 / 疑问"出发，不按教材章节。**
- 提一个你**真心想懂**的问题。例：
  - 为什么 $\int_a^b f = F(b)-F(a)$？
  - 线性代数**研究什么**？**解决什么问题**？**为何发明**？**形式为何如此**？
- 写成问题页的开头。

## ② 探界（探已知边界）

- 用你**已经会**的概念去顶这个问题：**顶到哪算哪**。
- 记录两侧：会什么（地板）／从哪不会（天花板）。
- **够不着 → 拆小**；**太简单 → 加难**。（问题要落在你能攀爬的高度）

## ③ 立骨（薄骨架）

- 先立**几个主干节点**（你自己认定的核心概念），**别急着铺开**。
- 教材目录**先不用**，留到第 ⑧ 拍体检。

## ④ 建模（通俗说清）

- 用**大白话**：它**研究什么**？**解决什么问题**？**为何存在**？
- 不堆术语；先要"人话版"。

## ⑤ 追问（发现路径）

- **为什么需要它？**（没它会怎样）
- **怎么会想到它？**（前人被什么逼出来的）
- **形式为何如此？**（为什么长这样）
- 目标：让它像**你自己发现的**，不是天上掉的。

## ⑥ 解构（纠错）

- 让**现象 / 事实**去顶你**之前的理解**。
- 顶不动 → 旧概念**不够用 / 错** → **当场拆、改**。
- 记录改了**什么**。**这一步不能省**（否则网长歪）。

## ⑦ 织网（`[[双向链接]]`）

- 每个新知识点：挂到相关**旧知识点**（`[[ ]]`）。
- 知识点之间**相互印证**（也 `[[ ]]`）。
- 问题页列清：**它长出的 N 个知识点** ＋ 链接。

## ⑧ 体检（查漏）

- 拿「**主观主干 ＋ 教材目录**」两层骨架对照。
- 标出：**缺口 / 断链 / 待证** → 写进 `账本.md`。
- **关网复述**：能否用自己的话把整张网讲一遍。
