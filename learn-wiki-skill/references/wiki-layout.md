# Wiki 目录结构与页面格式模板

> 本文件定义 learn-wiki-skill 的持久化结构。继承自 llm-wiki-skill 的链接规则与资料源模式。

## 目录结构

```
<项目>/
├── raw/源文件清单.md       # 资料登记（本地=存档副本；IMA=仅登记清单）
├── index.md                # 学习总入口：顶层核心问题 + 领域公式摘要 + 问题索引导航
├── log.md                  # 操作日志（仅追加）
├── WIKI-SCHEMA.md          # 模式与约定
└── wiki/
    ├── 00-领域公式.md       # 【根】顶层核心问题 + 领域公式 + Mermaid 协同架构图
    ├── 01-问题索引.md       # 从根到叶的问题清单（学习入口/自测清单）
    ├── 索引-<分类>.md       # 分类索引页
    └── <分类>/
        ├── <节点>.md        # 每个协同节点一页，内含若干三元组
        └── ...
```

## 链接规则（必须遵守）

- 使用标准 Markdown 相对路径 `[文本](./目标.md)`，**禁用裸 `[[wikilink]]`**。
- **跨目录前缀**（元文件在项目根，内容页在 `wiki/` 下）：
  - `wiki/<分类>/页面.md` → 根目录用 `../../index.md`，raw 用 `../../raw/x.md`，同级页面 `./x.md`，同级文件夹 `../<同级>/x.md`
  - `wiki/` 根的分类索引页 → 根目录用 `../index.md`，内容页用 `./<分类>/x.md`
- **导航栏**：每个页面标题后必须有 `> **导航**: [← 返回总纲](../index.md) | [领域公式](./00-领域公式.md) | [问题索引](./01-问题索引.md)`
- **双向链接**：A→B 则 B 必须有返回 A 的链接。
- **锚点链接**：`[文本](./页面.md#章节)`，锚点 = 小写标题、空格转连字符。

## 页面格式模板

```markdown

created: YYYY-MM-DD

tags: [领域公式, 顶层核心问题]

> **导航**: [← 返回总纲](../index.md) | [问题索引](./01-问题索引.md)

**<该领域要回答的根本性大问题>**

**<领域名> ≝ ⟨要素1, 要素2, 要素3, …⟩**

- 要素1：...
- 要素2：...

```mermaid

### 元文件

- **index.md**：总入口，含顶层核心问题、领域公式一行摘要、问题索引导航、分类导航。
- **log.md**：`## [YYYY-MM-DD] 操作类型 | 标题` 格式，仅追加。
- **WIKI-SCHEMA.md**：描述目录结构、页面模板、链接规则、工作流。

## 规模规则

- Wiki 内容页 **< 20 页**：index 用扁平树状大纲。
- **≥ 20 页**：index 只列分类标题链接到分类索引页，顶部加快捷检索表。
