# 六拍循环详解

> 每一轮答疑 = **接题 → 定位 → 检索 → 佐证 → 作答 → 归档**。一轮只答**一个问题**。

## ① 接题

1. **收截图** → `raw/images/YYYYMMDD-<slug>.<ext>`（只读、不可变）。
2. **多模态读图四件套**：① OCR；② 公式转录 LaTeX；③ 视觉描述；④ 关键洞察。
3. 写图文卡 `media/<slug>.md`（让截图**可被检索**）。
4. **保留你的疑问原话**（不要转述成我的理解）。
5. 缺上下文（哪本书 / 哪一章）→ **先问一句**再继续。

## ② 定位

1. **先查本地 wiki**：这个问题是否已被回答过？命中 → 直接回链旧答，再问"还有哪里不懂"。
2. 未命中 → 定位到**书目录的哪一章 / 哪个知识点**（决定挂载点）。
3. 该领域尚无 wiki → 先建最小结构（见 [archiving.md](archiving.md)）。

## ③ 检索

1. **乐享**：先关键词 `search_kb_search`，再语义 `search_kb_embedding_search`（参数 `filters.keyword`）。
2. **教材**：需要时查本地 PDF / 已登记源文件。
3. 记录**检索日期**（知识库内容可能过时）。

## ④ 佐证

| 情形 | 处理 |
|---|---|
| 截图 ↔ 乐享 ↔ 教材 **一致** | 采信，标三处出处 |
| **冲突** | **并列呈现并标注**，不擅自裁决 |
| 乐享**无结果** | 明说"未检索到，以下基于教材/通用知识" |

## ⑤ 作答

**先用工程/物理情境（必要）→ 再概念 →（可选）纯理性**（见 [grounding.md](grounding.md)）。
公式 / 函数图用 `math-render` 渲染成 PNG 并嵌入。

**苏格拉底式分级**：

| 你的反应 | 我的动作 |
|---|---|
| 答对 / 理解 | 下钻"为什么 / 如果…会怎样" |
| 半对 | 肯定对的，给**最小提示**再问 |
| 错 / 不会 | 退回**地基语言**提示 → 仍错才给完整解 |
| 直接说"给答案" | 立即给完整解 |

## ⑥ 归档

1. 写进 `wiki/<章>/index.md` 的 `Q<n>`（模板见 [answer-template.md](answer-template.md)）。
2. 截图图文卡已在 `media/`；生成图在该章 `img/`。
3. `log.md` 追加一行。
4. 答疑页 ⇄ 章节页 / 骨架页 **双向链接**。
5. 答不上或存疑 → `wiki/02-缺口账本.md`。
