# 纯概念页模板（→ wiki）

> **wiki 只放「纯知识」：概念 / 定义。没有问题、没有情景、没有推导**——那些都在 `问答知识库/`。
> 中间**穿插** math-render 渲染的公式 / 图。

## 完整模板

````markdown
# <概念名>

> **导航**: [← 返回总纲](../../../index.md) | [章页](../index.md) | [符号表](../../符号表.md)

> [!abstract] <概念 1>
> <一句定义>

> [!important] <概念 2>
> <一句定义>

> [!important] <概念 3>
> <一句定义>

![<图注>](./img/<名>.png)

## 相关页面
- [← 返回总纲](../../../index.md) | [章页](../index.md) | [符号表](../../符号表.md)
- 出处问答：[问答知识库/<slug>.md](../../../问答知识库/<slug>.md)
````

## 写作规则

| 规则 | 说明 |
|---|---|
| **只放定义** | 概念 / 定义；**不放问题、不放情景、不放推导** |
| 一个概念一卡 | 用 callout 承载定义 |
| 穿插公式图 | 公式 / 图用 math-render，插在定义之间 |
| 出处问答 | 底部链到产生它的问答记录 |
| 图随概念 | 生成图放 `<概念>/img/` |
