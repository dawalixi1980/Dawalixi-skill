# 工程 / 物理佐证规范（必要条件）

> **铁律**：回答**任何概念**，必须先摆出一个**工程或物理情境**把它"演"出来；**没有情境的解释 = 不合格**。
> 演完之后**可选**再纯理性地解释一遍。

## 为什么必要

概念若只停在抽象定义上，学习者无法真正"抓住"它。情境把概念变成**可感知、可计算、可证伪**的东西——
理解了情境，就理解了概念；算对了情境，就验证了理解。

## 好情境的五条标准

| 标准 | 说明 |
|---|---|
| **具体** | 有名有姓的场景（水箱、电路、弹簧…），不是"设某函数" |
| **有数** | 带数字与**单位**（$4.9\,t^2$ m、$5\,\Omega$…） |
| **可算** | 能真正算出结果 |
| **可证伪** | 情境能检验对错（算错就露馅） |
| **一一对应** | 情境中的对象 ↔ 概念要素一一对应 |

## 三步法

1. **情境**：摆出一个工程 / 物理场景，让人先"看见"问题。
2. **抽象**：从情境里抽出概念、符号与关系。
3. **（可选）纯理性**：给形式定义、性质、与相邻概念的关系。

## 情境来源库（按学科挑）

| 学科 | 可用情境 |
|---|---|
| 力学 | 自由落体、抛体、弹簧 $F=kx$、斜面 |
| 电学 | 电路 $V=IR$、电容充放电、RC 滤波 |
| 热/流体 | 水箱排水、热传导、管流 |
| 工程 | 传感器采样、信号、控制系统、结构受力 |
| 概率/统计 | 抽样检验、测量误差 |
| 经济/生物 | 复利、种群增长 |

## 反例（禁止）

- 架空举例、全程无数字（"比如一个函数…"）。
- 情境与概念**不对应**（讲导数却举了个静态例子）。
- 只在结尾补一句"例如…"敷衍了事。

> [!note] 纯理性解释（可选）
> <形式定义 / 性质 / 与相邻概念的关系>
