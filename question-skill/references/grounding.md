# 物理佐证规范（必要条件）

> **铁律**：回答**任何概念**，必须先摆出一个**物理 / 力学情境**把它"演"出来；**没有情境的解释 = 不合格**。
> **举例优先顺序：① 力学 → ② 计算机**（皆为真实应用）。**不写"纯理性"板块。**

## 为什么必要

概念若只停在抽象定义上，学习者无法真正"抓住"它。情境把概念变成**可感知、可计算、可证伪**的东西——
理解了情境，就理解了概念；算对了情境，就验证了理解。

## 好情境的五条标准

| 标准 | 说明 |
|---|---|
| **具体** | 有名有姓的场景（简支梁、柱、弹簧、数组…），不是"设某函数" |
| **有数** | 带数字与**单位**（$P=20\,\text{kN}$、$E=200\,\text{GPa}$…） |
| **可算** | 能真正算出结果 |
| **可证伪** | 情境能检验对错（算错就露馅） |
| **一一对应** | 情境中的对象 ↔ 概念要素一一对应 |

## 情境来源库（优先力学 ＋ 计算机）

| 领域 | 可用情境 |
|---|---|
| **力学 · 结构** | 简支梁受集中力的弯矩 / 剪力 / 挠度；柱的轴压稳定 $P_{cr}=\frac{\pi^2EI}{(\mu L)^2}$；桁架节点力平衡；应力-应变 $\sigma(\varepsilon)$ |
| **力学 · 基础** | 自由落体、抛体、弹簧 $F=kx$、斜面、动量 |
| **计算机** | 算法复杂度 $T(n)$、递归与递推、二叉树 / 栈 / 哈希、数据库 B+ 树索引、采样与误差 |
| **综合** | 用程序解梁的微分方程（有限元）；传感器采样做结构健康监测 |

## 范例：用「梁的挠度」讲导数链

> [!example] 力学情境
> 一根简支梁，跨中作用集中力 $P=20\,\text{kN}$，跨度 $L=6\,\text{m}$，抗弯刚度 $EI$。
> 关心梁**各处的挠度 $v(x)$**，以及它和**弯矩 $M(x)$、剪力 $V(x)$、荷载 $q(x)$** 如何互相推。

> [!important] 从中抽出概念
> 就是**逐次求导**的链条：
> $$q(x)=\frac{dV}{dx},\qquad V(x)=\frac{dM}{dx},\qquad M(x)=EI\,v''(x)$$
> "荷载 → 剪力 → 弯矩 → 挠度"是一条**导数链**——这正是"导数 = 变化率"在力学里的本体。

## 反例（禁止）

- 架空举例、全程无数字（"比如一个函数…"）。
- 情境与概念**不对应**（讲导数却举了个静态例子）。
- 只用抽象数学、完全不落地。
- 只在结尾补一句"例如…"敷衍了事。
