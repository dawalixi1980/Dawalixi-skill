# 归档规范（两层知识库）

> 核心：**问答（问题＋答案＋情景）进 `问答知识库/`；提炼的「纯概念 / 定义」进 `wiki/`。**
> `index.md` 同时导航两者：**问答目录** 与 **知识库目录**。

## 一、目录结构

```
<项目>/
├── index.md                       # 3 点 ＋ 问答目录 ＋ 知识库目录（书 TOC）
├── 问答知识库/                     # ★ 原始层：问 + 答
│   ├── index.md                   # 问题目录（列出每次问答）
│   └── YYYYMMDD-<slug>.md
├── library/                       # 知识性文件库
│   ├── 源文件清单.md
│   ├── books/                     # 书籍（整本 PDF）— 单独
│   └── lexiang/                   # 乐享下载：library/lexiang/<来源库>/
├── raw/                           # 截图（原图 ＋ 文字层）
├── log.md
└── wiki/                          # ★ 提炼层：纯概念 / 定义
    ├── 符号表.md                   # ★ 永久保留
    ├── <章>/index.md               # 章页（本章概念导航）
    ├── <章>/<概念>/index.md         # 纯概念页（只放定义）
    │   └── img/                   # 生成的公式 / 函数图
    └── 02-缺口账本.md              # 轻量版
```

## 二、两层职责

| 层 | 存什么 | 粒度 | 入口 |
|---|---|---|---|
| **问答知识库/** | 问 ＋ 答（含物理情景、推导） | 一次问答 = 一个文件 | `问答知识库/index.md` |
| **wiki/** | 从问答**提炼的纯知识**：概念 / 定义（**无问题、无情景**） | 一个概念 = 一个文件夹 | `index.md` 的知识库目录 |

> 一句话：**问答层是"过程"，wiki 层是"结论（定义）"。**

## 三、文件分类铁律

| 文件类型 | 去处 | 铁律 |
|---|---|---|
| **问答记录** | `问答知识库/YYYYMMDD-<slug>.md` | 问 与 答（含情景） |
| **书籍**（整本 PDF） | `library/books/` | 单独存放 |
| **乐享下载** | `library/lexiang/<来源库>/` | 按来源库分类 |
| 截图原图 / 文字层 | `raw/` | 原图 ＋ 文字层同放 |
| **生成的公式/函数图** | `wiki/<章>/<概念>/img/` | 概念级独立文件夹 |
| **纯概念页** | `wiki/<章>/<概念>/index.md` | 只放定义；无问题、无情景 |
| **符号表** | `wiki/符号表.md` | 永久保留 |

## 四、`index.md`（3 点 ＋ 两个导航）

```markdown
# 《书名》· 索引

> [!question] ① 核心问题（研究对象）
> <研究对象是什么>

> [!important] ② 整体架构（最简语言 ＋ 符号）
> <语言＋符号描述；符号最简解释见 符号表>

> [!tip] ③ 贯穿整个架构的核心要素
> <核心要素>

## 导航
| 入口 | 去向 |
|---|---|
| **问答目录** | [问答知识库](问答知识库/index.md) |
| **知识库目录** | 下方书籍目录（纯概念） |

## 知识库目录（教材）
| 章 | 标题 | 概念页 |
|:--:|---|---|
| 1 | … | [wiki/01-…/index.md](wiki/01-…/index.md) |
```

## 七、归类规则

| 事项 | 规则 |
|---|---|
| 原始层 | 「问 ＋ 答」→ `问答知识库/YYYYMMDD-<slug>.md`，并在 `问答知识库/index.md` 登记 |
| 提炼层 | **提炼纯概念 / 定义** → `wiki/<章>/<概念>/index.md`（无问题、无情景） |
| 图片 | 生成图跟概念走（`<概念>/img/`）；截图在 `raw/` |
| 回链 | 问答记录 ⇄ 概念页；章页 ⇄ 概念页；`index.md` ⇄ 各页（双向） |
| 存疑 | 记入 `02-缺口账本.md`（轻量） |
| 日志 | 每轮追加 `log.md` |

> **不建"问题索引"**：还没提问就不需要它。

## 八、无库时初始化

1. 建 `问答知识库/ library/books/ library/lexiang/ raw/ wiki/ log.md`。
2. 写 `index.md`（3 点 ＋ 两个导航）＋ `wiki/符号表.md` ＋ `wiki/02-缺口账本.md` ＋ `问答知识库/index.md`。
3. 按教材目录建章页；开始接第一个问答。
