# 归档规范（3 问核心 ＋ 书目导航）

> 核心：**只保留「3 个问题」的一个 markdown；其余按书籍目录做导航。**
> 共用 learn-skill / llm-wiki 的 wiki 底座。

## 一、目录结构

```
<项目>/
├── index.md                # 导航 = 按书籍目录（章 → 知识点）
├── 00-核心骨架.md          # ★ 只有 3 个问题
├── raw/
│   ├── 源文件清单.md
│   └── images/             # 截图原图（只读）
├── media/<slug>.md         # 截图图文卡（可检索）
├── log.md
└── wiki/
    ├── <章号-章名>/index.md # 每章一页，按 Q 序号累积答疑单元
    │   └── img/            # 该章公式图 / 函数图
    ├── 02-缺口账本.md
    └── 应用/钉子表.md
```

## 二、核心骨架：`00-核心骨架.md`（就这一张卡）

```markdown
# 00 · 核心骨架 —《书名 / 领域》

> [!abstract] ① 核心架构
> <这本书 / 知识点最核心的架构>

> [!important] ② 贯穿全文的核心元素
> <贯穿全部内容的最重要元素（地基）>

> [!question] ③ 研究方向（它要回答的问题）
> <它研究的根本问题>
```

## 三、index 导航：`index.md`

按**书籍目录**配置；无现成目录时按领域结构。

```markdown
# 《书名》· 导航

| 章 | 标题 | 知识点页 |
|:--:|---|---|
| 1 | … | [wiki/01-…/index.md](wiki/01-…/index.md) |
| 2 | … | … |
```

## 四、答疑单元挂载

| 事项 | 规则 |
|---|---|
| 位置 | 挂到**对应章节页** `wiki/<章>/index.md` 的 `Q<n>` |
| 编号 | 章内 `Q1、Q2…` 递增 |
| 图片 | 生成图跟该章走（`<章>/img/`）；截图走 `media/` 图文卡 |
| 回链 | 答疑单元 ⇄ 章节页 / `00-核心骨架.md` **双向** |
| 答不上 | 记入 `02-缺口账本.md`（open / resolved） |
| 日志 | 每轮追加 `log.md`：`## [YYYY-MM-DD] Q | <章·知识点>` |

## 五、无库时初始化

该领域还没有 wiki → 建上面最小结构：
1. 建 `raw/ raw/images/ media/ wiki/ log.md`。
2. 写 `00-核心骨架.md`（3 问）。
3. 从书里抄目录做 `index.md`。
4. 开始接第一个 `Q1`。
