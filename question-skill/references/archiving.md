# 归档规范（两层 ＋ 3 点 ＋ 书目导航 ＋ 文件分类）

> 核心：**两层归档** —— 原始「问答」进 `问答知识库/`；**提炼的知识点**进 `wiki/`。
> `index.md` 顶部只放 3 点；其余按书籍目录做导航。文件**按类分开存放，绝不混放**。

## 一、目录结构

```
<项目>/
├── index.md                       # 顶部 3 点 ＋ 下面书目导航
├── 问答知识库/                     # ★ 原始层：每次「问 + 答」
│   └── YYYYMMDD-<slug>.md
├── library/                       # 知识性文件库（按类）
│   ├── 源文件清单.md
│   ├── books/                     # 书籍（整本 PDF 等）— 单独
│   └── lexiang/                   # 乐享下载：library/lexiang/<来源库>/
├── raw/                           # 截图归档（原图 ＋ 文字层，同放）
│   ├── YYYYMMDD-<slug>.png
│   └── YYYYMMDD-<slug>.md
├── log.md                         # 操作日志（保留）
└── wiki/                          # ★ 提炼层：知识点
    ├── 符号表.md                   # ★ 永久保留，不可删
    ├── <章号-章名>/index.md          # 章页（本章知识点导航）
    ├── <章号-章名>/<知识点>/index.md  # 知识点页（3 板块）
    │   └── img/                    # 生成的公式 / 函数图（知识点级）
    └── 02-缺口账本.md               # 轻量版
```

## 二、两层职责

| 层 | 存什么 | 粒度 |
|---|---|---|
| **问答知识库/**（原始层） | 提问 ＋ 完整回答（含截图、依据） | 一次问答 = 一个文件 |
| **wiki/**（提炼层） | 从问答中**提炼的知识点**（3 板块） | 一个知识点 = 一个文件夹 |

> 问答记录是"对话存档"，wiki 是"精炼可复用的知识"；两者**双向链接**。

## 三、文件分类铁律

| 文件类型 | 去处 | 铁律 |
|---|---|---|
| **问答记录** | `问答知识库/YYYYMMDD-<slug>.md` | 原始层，保留问与答 |
| **书籍**（整本 PDF） | `library/books/` | **单独**，不与截图等零碎混放 |
| **乐享下载**（PDF/PPT/Word…） | `library/lexiang/<来源库>/` | 按**来源库**分类 |
| 截图原图 | `raw/` | 只读、不可变 |
| 截图文字层 | `raw/<slug>.md` | 与图**同放**，可检索 |
| **生成的公式/函数图** | `wiki/<章>/<知识点>/img/` | **知识点级独立文件夹** |
| 知识点页 | `wiki/<章>/<知识点>/index.md` | 3 板块 |
| **符号表** | `wiki/符号表.md` | **永久保留** |

> 总则：**任何外来文件或生成的图片，先归到对应文件夹；禁止堆在根目录或互相混放。**

## 四、`index.md`（顶部 3 点 ＋ 书目导航）

> [!important] 3 点定义（顺序固定）
> ① **核心问题** —— 这个知识点研究的**对象**是什么
> ② **整体架构** —— 用**语言 ＋ 符号**描述整个架构；符号用**最简语言**解释（详见 `符号表`）
> ③ **贯穿整个架构的核心要素** —— 贯穿全部内容的那一个核心要素

```markdown
# 《书名》· 学习索引

> [!question] ① 核心问题（研究对象）
> <这个知识点研究的对象是什么>

> [!important] ② 整体架构（用最简语言 ＋ 符号）
> <用语言和符号描述整个架构>
> 符号最简解释见 → [符号表](wiki/符号表.md)

> [!tip] ③ 贯穿整个架构的核心要素
> <贯穿全部内容的核心要素>

## 导航（教材目录）
| 章 | 标题 | 页面 |
|:--:|---|---|
| 1 | … | [wiki/01-…/index.md](wiki/01-…/index.md) |
```

## 五、问答知识库记录模板

```markdown
---
date: YYYY-MM-DD
出处: 《书名》· 第 X 章
知识点: wiki/<章>/<知识点>/index.md
tags: [...]
---

# 问：<一句话问题>

## 问
<原话（小问列表）>

## 答
<完整回答（3 板块：问题 / 概念 / 物理情景）>

## 提炼的知识点
→ 已归档到 [wiki/<章>/<知识点>/index.md](../../wiki/<章>/<知识点>/index.md)
```

## 六、归类规则

| 事项 | 规则 |
|---|---|
| 原始层 | 「问 + 答」写进 `问答知识库/YYYYMMDD-<slug>.md` |
| 提炼层 | 知识点写进 `wiki/<章>/<知识点>/index.md`（3 板块） |
| 图片 | 生成图跟知识点走（`<知识点>/img/`）；截图在 `raw/` |
| 回链 | 问答记录 ⇄ 知识点页 / 章页 / `index.md` **双向** |
| 存疑 | 记入 `02-缺口账本.md`（**轻量** open / resolved） |
| 日志 | 每轮追加 `log.md` |

> **不建"问题索引"**：还没提问就不需要它。

## 七、无库时初始化

1. 建 `问答知识库/ library/books/ library/lexiang/ raw/ wiki/ log.md`。
2. 写 `index.md`（3 点 ＋ 书目导航）＋ `wiki/符号表.md` ＋ `wiki/02-缺口账本.md`。
3. 按教材目录建章页；开始接第一个问答。
