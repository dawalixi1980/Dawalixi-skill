# 归档规范（3 点 ＋ 书目导航 ＋ 文件分类）

> 核心：**`index.md` 顶部只放 3 点；其余按书籍目录做导航。**
> 文件**按类归档**——书籍、乐享下载、截图**分开存放，绝不混放**。

## 一、目录结构

```
<项目>/
├── index.md                       # 顶部 3 点 ＋ 下面书目导航
├── library/                       # 知识性文件库（按类）
│   ├── 源文件清单.md
│   ├── books/                     # 书籍（整本 PDF 等）— 单独
│   └── lexiang/                   # 乐享下载：library/lexiang/<来源库>/
├── raw/                           # 截图归档（原图 ＋ 文字层，同放）
│   ├── YYYYMMDD-<slug>.png
│   └── YYYYMMDD-<slug>.md
├── log.md                         # 操作日志（保留）
└── wiki/
    ├── 符号表.md                   # ★ 永久保留，不可删
    ├── <章号-章名>/index.md          # 章页（本章知识点导航）
    ├── <章号-章名>/<知识点>/index.md  # 知识点页（答疑单元 Q<n>）
    │   └── img/                    # 生成的公式 / 函数图（知识点级）
    └── 02-缺口账本.md               # 轻量版
```

## 二、文件分类铁律

| 文件类型 | 去处 | 铁律 |
|---|---|---|
| **书籍**（整本 PDF） | `library/books/` | **单独**，不与截图等零碎混放 |
| **乐享下载**（PDF/PPT/Word…） | `library/lexiang/<来源库>/` | 按**来源库**分类 |
| 截图原图 | `raw/` | 只读、不可变 |
| 截图文字层 | `raw/<slug>.md` | 与图**同放**，可检索 |
| **生成的公式/函数图** | `wiki/<章>/<知识点>/img/` | **知识点级独立文件夹** |
| 答疑单元 `.md` | `wiki/<章>/<知识点>/index.md` | 按知识点累积 `Q<n>` |
| **符号表** | `wiki/符号表.md` | **永久保留**，解释所有基础符号 |

> 总则：**任何外来文件或生成的图片，先归到对应文件夹；禁止堆在根目录或互相混放。**

## 三、`index.md`（顶部 3 点 ＋ 书目导航）

> [!important] 3 点定义（顺序固定）
> ① **核心问题** —— 这个知识点研究的**对象**是什么
> ② **整体架构** —— 用**语言 ＋ 符号**描述整个架构；符号用**最简语言**解释（详见 `符号表`）
> ③ **贯穿整个架构的核心要素** —— 贯穿全部内容的那一个核心要素

```markdown
# 《书名》· 学习索引

> [!question] ① 核心问题（研究对象）
> <这个知识点研究的对象是什么>

> [!important] ② 整体架构（用最简语言 ＋ 符号）
> <用语言和符号描述整个架构>
> 符号最简解释见 → [符号表](wiki/符号表.md)

> [!tip] ③ 贯穿整个架构的核心要素
> <贯穿全部内容的核心要素>

## 导航（教材目录）
| 章 | 标题 | 页面 |
|:--:|---|---|
| 1 | … | [wiki/01-…/index.md](wiki/01-…/index.md) |
| 2 | … | … |
```

## 四、归类规则

| 事项 | 规则 |
|---|---|
| 位置 | 答疑单元挂到 **`wiki/<章>/<知识点>/index.md`** 的 `Q<n>` |
| 编号 | 知识点内 `Q1、Q2…` 递增 |
| 图片 | 生成图跟知识点走（`<知识点>/img/`）；截图在 `raw/` |
| 回链 | 知识点页 ⇄ 章页 / `index.md` **双向** |
| 存疑 | 记入 `02-缺口账本.md`（**轻量** open / resolved） |
| 日志 | 每轮追加 `log.md`：`## [YYYY-MM-DD] Q | <章·知识点>` |

> **不建"问题索引"**：还没提问就不需要它；答疑单元本身就是索引。

## 五、无库时初始化

该领域还没有 wiki → 建上面最小结构：
1. 建 `library/books/ library/lexiang/ raw/ wiki/ log.md`。
2. 写 `index.md`（顶部 3 点 ＋ 书目导航）＋ `wiki/符号表.md` ＋ `wiki/02-缺口账本.md`。
3. 按教材目录建章页；开始接第一个 `Q1`。
