# 回答卡片模板

> 顺序固定：**① 出处 → ② 疑问 → ③ 一句话答案 → ④ 佐证 → ⑤ 情境作答 → ⑥ 归类**。
> 卡片（callout）＋ 表格呈现；公式 / 图用 math-render 出 PNG。**结论先行**。

## 完整模板

````markdown
# Q<n>：<一句话问题>

> [!info] 出处
> 《书名》· 第 X 章 <章名> · <节/知识点>　｜　截图：[raw/<slug>.md](../../../raw/<slug>.md)

> [!question] 疑问
> <你的原话>

> [!abstract] 一句话答案
> <结论先行，1–2 句>

> [!quote] 乐享佐证
> 《文档名》：<关键结论>　（链接 / 检索日期 2026-10-04）

> [!quote] 教材佐证
> 《书名》第 X 页：<相关段落要点>

> [!example] 工程 / 物理情境（必要，优先土木/计算机）
> <具体场景，带数字与单位>

> [!important] 从中抽出概念
> <定义 + 与情境要素的对应>

> [!note] 纯理性解释（可选）
> <形式定义 / 性质 / 与相邻概念的关系>

![<图注>](./img/<名>.png)

> [!tip] 归类
> 挂到：<书 第 X 章 · 知识点>　｜　相关：<相邻 Q / 知识点页>
````

## 写作规则

| 规则 | 说明 |
|---|---|
| 出处最前 | **必须先标"哪本书·哪一章"**，再解答 |
| 一问一卡 | 每个 Q 只解决一个问题 |
| 结论先行 | `一句话答案` 必须在佐证之前 |
| 情境必要 | 无工程/物理情境 = 不合格；优先土木/计算机 |
| 出处齐全 | 截图 / 乐享 / 教材三处尽量齐 |
| 图随知识点 | 生成图放该知识点 `img/`，正文相对路径嵌入 |
| 归类落库 | 写进 `wiki/<章>/<知识点>/`；存疑记 `02-缺口账本.md` |
