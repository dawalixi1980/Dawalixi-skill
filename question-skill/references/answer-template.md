# 回答卡片模板（3 板块）

> 顺序固定：**小框「出处」 → ① 问题 → ② 概念（答小问） → ③ 物理情景**。
> **中间穿插** math-render 渲染的公式 / 图。**不写"纯理性"板块。**

## 完整模板

````markdown
# <知识点标题>

> [!info] 出处
> 《书名》· 第 X 章　｜　《普林斯顿微积分读本》第 Y 章

---

## ① 问题

> [!question] 疑问
> - <小问 1>
> - <小问 2>
> - <小问 3>

---
````

## 写作规则

| 规则 | 说明 |
|---|---|
| **只 3 板块** | ① 问题 · ② 概念 · ③ 物理情景 |
| 小框出处 | 用 `[!info]` 小框标《书》· 章（可附《普林斯顿》对应章） |
| 概念答小问 | 概念板块按"小问 ①②③"逐条回答 |
| 物理情景优先 | **力学 → 计算机** 的实际应用 |
| 穿插公式图 | 公式 / 图用 math-render，插在概念或情景**中间** |
| **不写纯理性** | 删除"纯理性解释"板块 |
| 图随知识点 | 生成图放该知识点 `img/` |
| 归类落库 | 写进 `wiki/<章>/<知识点>/`；存疑记 `02-缺口账本.md` |
