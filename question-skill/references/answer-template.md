# 回答卡片模板

> 所有回答用**卡片（callout）＋ 表格**呈现；公式 / 图用 math-render 出 PNG。**结论先行**。

## 完整模板

````markdown
# Q<n>：<一句话问题>

> [!question] 疑问
> <你的原话>

> [!info] 截图
> [media/<slug>.md](../../../media/<slug>.md)

> [!abstract] 一句话答案
> <结论先行，1–2 句>

> [!quote] 乐享佐证
> 《文档名》：<关键结论>　（链接 / 检索日期）

> [!quote] 教材佐证
> 《书名》第 X 页：<相关段落要点>

> [!example] 工程 / 物理情境（必要）
> <具体场景，带数字与单位>

> [!important] 从中抽出概念
> <定义 + 与情境要素的对应>

> [!note] 纯理性解释（可选）
> <形式定义 / 性质 / 与相邻概念的关系>

![<图注>](./img/<名>.png)

> [!tip] 关联
> 挂载：<书 第 X 章 · 知识点>　｜　相关：<相邻 Q / 要素页>
````

## 写作规则

| 规则 | 说明 |
|---|---|
| 一问一卡 | 每个 Q 只解决一个问题 |
| 结论先行 | `一句话答案` 必须在最前 |
| 情境必要 | 无工程/物理情境 = 不合格 |
| 出处齐全 | 截图 / 乐享 / 教材三处尽量齐 |
| 图随知识点 | 生成图放本章 `img/`，正文相对路径嵌入 |
| 状态可追踪 | 问题索引状态 / 缺口账本同步 |
```
