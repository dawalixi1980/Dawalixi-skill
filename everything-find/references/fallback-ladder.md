# 删词阶梯(搜索无结果时的自动降级)

**触发条件**:原始查询命中 0 条。**目的**:用户给的名称往往带着自己记忆里的噪声(编号、副本序号、单位后缀、多余描述),原样查不到时,**由 LLM 自行删词重搜,不要回头问用户"是不是别的名字"**。

**硬规则**

- 最多 4 轮,首次命中即停;
- 每轮必须留痕(轮次 / 实际查询串 / 命中数),交付时要写清用了第几轮、删了什么;
- **任何一轮查询串为空/纯空白 → 跳过**(Everything 空查询会返回全盘所有文件);
- 4 轮仍 0 → 报 `NO_MATCH`,给 2 条改词建议;
- 阶梯只做"删词/放宽",不做"换意思"——不许把"路基"自作主张换成"路面"。

## 四轮定义

| 轮 | 动作 | 实现 | 例 |
|---|---|---|---|
| **R1** | 去扩展名与常见尾缀 | 去掉 `.扩展名`;去掉 `- 副本`、`(1)`、`（2）`、`_v2`、`最终版`、`final`、`备份` 等尾缀 | `路基大样图.dwg` → `路基大样图` |
| **R2** | 去括号内容与流水编号 | 去掉 `（…）`、`(…)`、`【…】`、`[…]`;去掉开头 `\d{1,4}[-_.、 ]` 形式的编号 | `03 路基防护（含边坡）` → `路基防护` |
| **R3** | 拆词,留最长的 **2 个**特征词(AND) | 按空白与 `· 、 , . （）` 等切词(连字符**不**切,`AD-03` 要保留完整),按字数取最长 2 个 | `AD-03 一般路基设计图` → `AD-03 一般路基设计图` |
| **R4** | 只留最长的 **1 个**特征词 | 取最长词 | `一般路基设计图` |
| **R4b** | 仍 0 且该词长 ≥4 → 前缀通配 | `词*` | `一般路基设计图*` |
| **R5** | **目录枚举**(不是删词,是换打法):定位可疑目录后用 `-Path` + `ext:pdf` 之类列出该目录,人工/LLM 比对文件名 | `ev-search.ps1 -Query "ext:pdf" -Path "Z:\…\方案设计（评审后最新版）\河西街道（6.0m路面宽）"` | 实测:按名字搜恒 0,枚举目录一次命中 |

## 名称变体:为什么 R5 必须有

真实案例(2026-10-14):用户给「示例市河西街道**安马屯**至新屋等2条线路硬底化工程(**崆垌**村委会)」,
索引里的文件是「示例市河西街道**马安屯**至新屋等2条线路硬底化工程(**崆峒**村委会).pdf」——
**语序颠倒**(安马屯 ↔ 马安屯)+ **异体字**(垌 ↔ 峒)。逐字删词永远命中不了,只有枚举目录才能发现。

常见变体(枚举时按这些找差异):

| 类型 | 例 |
|---|---|
| 语序 | 安马屯 ↔ 马安屯 |
| 异体/形近字 | 崆垌 ↔ 崆峒 ↔ 崆坰;滘 ↔ 窖 |
| 全角/半角括号、顿号 | `（新云村委会）` ↔ `(新云村委会)` |
| 简繁 | 台 ↔ 臺 |
| 路面宽等设计变体 | `河西街道（3.5m路面宽）` / `河西街道（6.0m路面宽）` 是**两套不同图纸**,别串 |
| 同一项目的不同文件用不同写法 | 方案设计里写「马安屯/崆峒」,交通局的批复里写「安马屯/崆坰」 |

枚举时的判据:目录名里的项目/街道/路面宽 + 文件名里的工程名主干 + 文件大小(整套方案设计通常十几 MB,单册分表多为几百 KB)。

## 留痕格式(交付时必须给出)

```
查询词:"AD-03 一般路基设计图 副本1 (1)"
阶梯:R0 0 命中 → R1 0 → R2 "AD-03 一般路基设计图" 命中 12 条(采用 R2)
```

## 何时不该用阶梯

- 用户明确要求**精确匹配某个文件名**(如"只找叫 X 的文件")→ 仍可跑阶梯,但交付时必须说明"原串无命中,以下是放宽后的结果",不得让放宽结果冒充精确结果;
- 命中 0 是因为**约束太严**(`ext:`/`path:`/`dm:` 过滤)→ 先放宽过滤条件,再动名称词,并在留痕里区分"放宽过滤"与"删词";
- 工具不可用(`TOOL_UNAVAILABLE`)→ **不许用阶梯假装搜过**,直接报不可用。

## 反例(不许做)

| 反例 | 为什么错 |
|---|---|
| 原串 0 命中,直接回"没有这个文件" | 违反阶梯要求;应先删词重试 |
| 把"路基防护设计图"改成"道路结构图"再搜 | 换意思了,属于编造用户意图 |
| 只留"图"一个词,搜出 8 万条,取前 5 条交差 | 过度放宽,候选无意义;应保留最特征词并收窄 |
| 阶梯跑了但交付不写轮次 | 用户无法判断结果可靠度 |
