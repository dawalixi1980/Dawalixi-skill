# TARGET —— 目标与非目标

## 目标(必须做到)

1. **接入本机 Everything**,让"按名称找文件"变成毫秒级全盘检索,而不是遍历目录。
2. **结果必须含完整绝对路径**,直接来自索引,可复制即用。
3. **按用户给的名称搜索**:由 LLM 从候选里判定**最匹配的是哪一个**,并固定输出 **5 选 markdown 表格**。
4. **搜不到时自行降级**:按删词阶梯(R1–R4)删词/放宽重搜,不许直接回"没找到",更不许编造。
5. **可机检**:契约有校验器,搜索行为有回归测试(含正例、近似误匹配反例、无结果、限目录)。

## 成功判据

- `ev-search.ps1 -Query "<名称>" -Ladder` 能返回含 `results[].path` 的 JSON,控制台只有一行 ASCII 摘要;
- 带噪声的名称(如 `X 副本1 (1)`)能通过阶梯找回正确文件,并如实记录用了第几轮;
- 候选为 0 时 `error_code = NO_MATCH`,且 `results` 为空;
- `validate_skill.py` 与两个测试脚本全绿;
- 装到 `$DSH_HOME\skills\everything-find` 后,新会话的技能目录里能看到它。

## 非目标(不做)

- 不做文件管理(打开/移动/改名/删除/复制);
- 不读文件内容、不做 OCR/看图判断"这份图纸对不对";
- 不替代人工确认:LLM 的"最匹配"是建议,用户仍可否掉;
- 不做多机/云盘联合检索;不自己重建索引(索引归 Everything)。
