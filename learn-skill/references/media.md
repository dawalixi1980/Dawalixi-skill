# 图片资料归档规范（media）— learn-skill

> 图片是一等资料。**图片本身不可检索**，所以每张输入图都要配一张"文字层"图文卡。

## 一、两类图片 + 存放（与知识点同处一地）

| 类型 | 来源 | 存放 | 可变性 |
|---|---|---|---|
| **输入原图** | 截图 / 拍照 / 扫描 / 书本图 / 白板 | `raw/images/YYYYMMDD-<slug>.<ext>` | **不可变**（只读存档） |
| **生成图** | math-skill 渲染的公式 / 函数图 | **该知识点文件夹内** `wiki/<分类>/<要素>/img/` | 可再生成 |

**规则**：生成图**属于哪个知识点，就放那个知识点的文件夹里**（与 `index.md` 同级同目录族，不集中堆到全局桶）。因为一个知识点 = 一个文件夹，图片天然跟它走。

## 二、命名

- 输入原图：`raw/images/20260914-lagrange.png`
- 图文卡：`media/20260914-lagrange.md`（同 slug 配对）
- 生成图：`wiki/<分类>/<要素>/img/<语义名>.png`，如 `wiki/微积分/极限/img/epsilon-delta.png`

## 三、图文卡格式：`media/<slug>.md`

```markdown
---
title: <一句话标题>
type: media
source_image: raw/images/<file>
media_kind: screenshot | photo | diagram | whiteboard | book-figure
page: wiki/<分类>/<要素>/index.md
core: <关联的领域公式>
created: YYYY-MM-DD
tags: [...]
---

# <标题>

![原图](../raw/images/<file>)

> 来源：<书/页/网站/拍摄者>　·　图注：<一句话>

## 文字层（OCR）
<图中所有文字；公式一律用 LaTeX 转录。>

## 视觉描述
<结构 / 数据流 / 控制流；要求不看原图也能理解。>

## 关键洞察
<最核心的 1–3 点。>

## 公式复现（如有）
![复现](../wiki/<分类>/<要素>/img/<名>.png)
<用 math-skill 还原图中公式，便于对照与检索。>

## 关联
- 知识点页：[<要素>](../wiki/<分类>/<要素>/index.md)
- 钉住要素：<骨架里对应的顶层要素 / 地基>

## 相关页面
- [← 返回总纲](../index.md)
```

## 四、多模态摄入流程（每张图）

1. **收图** → 复制进 `raw/images/`，命名 `YYYYMMDD-<slug>`（原图之后不改）。
2. **读图（多模态模型）** → 四件套：① OCR；② 公式转录 LaTeX；③ 视觉描述；④ 关键洞察。
3. **写图文卡** → `media/<slug>.md`（用上面模板）——**这一步让图片可被 grep 检索**。
4. **归属知识点** → 判断它作用于骨架的哪个要素、挂在哪条支撑线上，把引用写进对应要素页 `wiki/<分类>/<要素>/index.md`。
5. **复现公式** → 若图含公式，用 math-skill 渲染到**该知识点的** `img/`，与 OCR 一起写进图文卡。
6. **登记 & 日志** → `raw/源文件清单.md` 加一行（类型"图片"）；`log.md` 追加 `## [YYYY-MM-DD] 图片摄入 | <标题>`。

## 五、页面引用（相对路径）

要素页 `wiki/<分类>/<要素>/index.md`：
- 输入原图：`![图注](../../../raw/images/<file>)`
- 生成图：`![图注](./img/<file>)`
- 图文卡：`> 图文卡：[<标题>](../../../media/<slug>.md)`

骨架页 `wiki/00-骨架/index.md`：
- 生成图：`![图注](./img/<file>)`
- 输入原图：`![图注](../../raw/images/<file>)`

**每张嵌入图必须带**：图注 + 来源（+ 图文卡链接，若有）。

## 六、与 D v4「四模式」配合

书本**架构图/流程图**：图文卡的「视觉描述」= 模式1；要素页另出 Mermaid = 模式2；卡里写「原图定位」= 模式4。图片既被归档，又被转成可渲染、可检索的结构。若图中有公式/函数曲线，用 math-skill 生成图（= 可复现资产）。

## 七、检查清单

- [ ] 输入图都在 `raw/images/`，且各有同 slug 的 `media/` 图文卡
- [ ] 图文卡含 OCR（公式为 LaTeX）与视觉描述（可 grep）
- [ ] 生成图放在对应知识点的 `img/` 目录
- [ ] 图片归属到正确的要素，并挂到地基支撑线
- [ ] `raw/源文件清单.md` 与 `log.md` 已更新
