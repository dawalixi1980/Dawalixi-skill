# 一体知识点单元 — 模板与示例

> 每个知识点 = 一个"在地基元素上生长的操作 / 关系"。要素页由若干单元组成。
> **图片跟知识点走**：本页的公式图/函数图放在同目录 `img/`，正文用 `./img/<名>.png` 引用。

## 最小档（默认）

```markdown
## Q<n>：<具体问题>
- **符号**：<公式 / 代码>
  ![<图注>](./img/<名>.png)　·　来源：<math-skill 生成 / 某书某页>
- **语义**：这个要素在顶层"在说什么"。
- **机制**：它如何作用在【<地基元素>】上（作用于它 / 相对它成立 / 由它组成）。
- **定位**：挂载在连结图 ⟨…⟩ 的 <节点 / 支撑线>，对地基的 <什么运算>。
```

## 完整档（复杂概念追加）

```markdown
- **协同演示**：<要素A> → <要素B> → <要素C> —— <一条符号链>
- **双向标注**：底→顶 <…>；顶→底 <…>
- **钉子**：<现实问题>（顶坐标 <要素> / 底坐标 <地基>）
- **图文卡**：[<标题>](../../../media/<slug>.md)（若来自输入截图）
```

> 双向标注若已在骨架页做过全局标注，此处只在该单元方向容易混时才写。

## 示例（微积分 · 地基＝函数）

```markdown
## Q1：怎么描述一个量"变化得多快"？
- **符号**：$f'(x)=\lim_{\Delta x\to0}\dfrac{f(x+\Delta x)-f(x)}{\Delta x}$
  ![导数的定义](./img/derivative-def.png)　·　来源：math-skill 生成
- **语义**：顶层要素「变化率」——瞬时变化的速度。
- **机制**：对【函数 f(x)】逐点作极限运算（作用于它）。
- **定位**：连结图 ⟨变化率 d/dx, 累积 ∫, 互逆 FT⟩ 的 **d/dx** 节点，对函数求极限商。
- **协同演示**：里程 f → 变化率 f' → 再累积 ∫f' 回到 f（互逆）。
- **钉子**：汽车速度表由里程随时间的变化率算得。
- **图文卡**：[课堂笔记-导数几何意义](../../../media/20260914-derivative-geo.md)
```

## 完整档示例（牛顿力学 · 地基＝惯性系）

```markdown
## Q2：为什么"力 = 质量 × 加速度"只在某些参考系成立？
- **符号**：$\vec F=m\vec a$
  ![牛顿第二定律](./img/newton-second.png)
- **语义**：顶层要素「力与运动」。
- **机制**：**相对【惯性系】才成立**（背景型地基）。
- **定位**：连结图 ⟨惯性, 力 F=ma, 反作用⟩ 的 **F=ma** 节点，前提是惯性系。
- **协同演示**：惯性系 F=0 ⇒ 匀速 → 非零 F ⇒ a=F/m → 反作用 -F。
- **双向标注**：底→顶 惯性系是三定律共同前提；顶→底 三定律都以惯性系为绝对背景。
- **钉子**：电梯加速上升时体重计读数变化（需在惯性系下分析视重）。
```

## 写作规则

- 每个单元**只解决一个**问题，问题必须能由「符号」直接回答。
- **机制**字段必填——没写"作用在地基上"= 悬空砖块。
- 公式/函数图用 math-skill 渲染到本页 `img/`；输入截图走 `media/` 图文卡（见 [media.md](media.md)）。
- 单元按"从根到叶"排列：要素识别 → 协同关系 → 细节参数。
