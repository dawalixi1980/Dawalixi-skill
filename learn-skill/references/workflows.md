# 工作流 — 建库 / 摄入 / 教学 / 自测 / 复习 / 健康检查

> learn-skill 的操作层。图片规范见 [media.md](media.md)，结构见 [wiki-layout.md](wiki-layout.md)。

## A. 建立新的学习 Wiki

```bash
python <skill-dir>/scripts/init-wiki.py --path <项目目录> --domain "<领域名>"
```

生成骨架后**必须完成**：
1. 确定**顶层核心问题** → 写入 `wiki/00-骨架/index.md`。
2. 提炼**领域公式**（要素 3±1）+ 输出 **Mermaid 协同图**。
3. **找地基元素** + 填**贯穿度自检表**；输出**连结关系图**并做双向标注。
4. 创建 `wiki/01-问题索引.md` 初版清单（≥5 题，由浅入深）。

## B. 摄入资料（增量学习）

**一次只摄入一份，保证质量。**

### B1. 文本资料
1. **判断资料源**
   - 本地文件 → 存入 `raw/`（只读存档）后直接读取。
   - IMA 向量库 → 用 ima-skill 的 `search_knowledge` 向量检索识别，仅在 `raw/源文件清单.md` 登记，**不下载**。
2. **定位挂载点**：这份资料回答哪些问题？对应骨架 ⟨…⟩ 的哪个要素 / 地基的哪种运算？
3. **提炼一体单元**：提取「问题 → 符号 → 一体知识点」写入 `wiki/<分类>/<要素>/index.md`（模板见 unit-template.md）。
4. **渲染符号**：公式/图按下方「渲染规范」出 PNG（放进该知识点的 `img/`）并嵌入。
5. **更新问题索引** → `01-问题索引.md`。
6. **必要时修订骨架** → `00-骨架/index.md` 的公式/图/自检表。
7. **记录日志** → `log.md` 追加 `## [YYYY-MM-DD] 摄入 | <标题>`。
8. **健康检查** → 见 F。

### B2. 图片资料（截图 / 拍照 / 书本图）
按 [media.md](media.md) 的多模态流程执行：
1. 收图 → `raw/images/YYYYMMDD-<slug>.<ext>`（原图不可变）。
2. **多模态读图** → 四件套：① OCR；② 公式转录 LaTeX；③ 视觉描述；④ 关键洞察。
3. 写图文卡 `media/<slug>.md`（**让图片可被 grep 检索**）。
4. 归属到对应要素文件夹，把引用写进该要素页。
5. 若含公式 → 用 math-skill 渲染到**该知识点的** `img/` 并写进图文卡。
6. 登记 `raw/源文件清单.md` + 日志。

## C. 教学（用户说"教我/学习某领域"）

按 learning-arch-d.md 的 11 条要求授课，并**同步持久化**：
- 第 0 遍 → 骨架页；第 0.5 遍 → 地基节 + 自检表；
- 第 1 遍 → 每个要素一个 `wiki/<分类>/<要素>/index.md` + ≥1 个一体单元；
- 结束 → 鼓励用户重绘连结图，重绘图存入该页 `img/`（可选）。

## D. 第 2 遍自测（下山）与缺口

1. 合上骨架页的连结图，**只看顶层领域公式**。
2. 逐个要素自问："它如何作用在地基 `<元素>` 上？"
3. 推得出 → 掌握；**推不出 → 记入 `02-缺口账本.md`（open）**。
4. 补强后改 `resolved`。

## E. 间隔复习

1. 按 **1 / 3 / 7 / 30 天** 复查 `01-问题索引.md`。
2. **只看问题不看答案**。
3. 答对 → `[x]` 记日期；答错 → 降级回 `[ ]` 并**补强该单元的「协同演示」**。

## F. 健康检查（定期）

- 搜索 `](./xxx.md)`，验证目标文件存在（无断链）。
- A→B 则 B 必有返回 A（无单向链接）。
- 检查孤立页（无入链）。
- 检查"悬空砖块"：任何要素页/单元没标「对地基的什么运算」→ 不合格。
- **检查图片**：每个 `raw/images/*` 都有同 slug 的 `media/*.md` 图文卡；页面嵌入图都带图注与来源。
- `grep "^## \[" log.md | tail -5` 追踪摄入历史。

## 渲染规范（math-render / math-skill）

**图片跟随知识点**：生成图放进该知识点的 `wiki/<分类>/<要素>/img/`，骨架图放 `wiki/00-骨架/img/`。

```bash
# 公式
node <math-skill>/scripts/render_formula.js "\int_a^b f(x)\,dx=F(b)-F(a)" \
  --name <语义名> -o <项目>/wiki/<分类>/<要素>/img/<语义名>.png
# 函数/几何图
python <math-skill>/scripts/render_plot.py spec.json \
  -o <项目>/wiki/<分类>/<要素>/img/<语义名>.png
```

规则：
- 文件名语义化（如 `derivative-def.png`）；正文用相对路径 `./img/<名>.png` 嵌入。
- frontmatter 的 `images:` 字段登记本页图片；`symbol` 字段保留 LaTeX 源码。
- Mermaid 图同时保留代码块。终端不渲染 LaTeX，**重点公式一律出图**。

## 资料源模式细节

### IMA 向量库模式
1. 先加载 ima-skill，校验凭证。
2. `search_knowledge_base`（query 传空）盘点知识库，定位目标库。
3. `search_knowledge` 多主题语义检索，读 `title`/`highlight_content` 判断重点。
4. `get_knowledge_list` 按文件夹浏览，确保无遗漏。
5. 仅在 `raw/源文件清单.md` 登记，**绝不下源文件**。
6. 需要原文时用 `get_media_info` 获取 URL 按需读取。
