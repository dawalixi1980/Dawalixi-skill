# TARGET —— 目标与非目标

## 目标(必须做到)

1. **在 git 不可用时也能上传**:只用 HTTPS + REST API 完成一次真实提交;
2. **凭据发现自动化**:环境变量 → `gh auth token` → `git credential fill`,不要求用户手工粘 token;
3. **中文/二进制都不出错**:非 ASCII 转 `\uXXXX` 发 ASCII 字节,二进制走 base64;
4. **上传前有闸**:干跑清单 + 疑似密钥拦截 + 脱敏提醒;
5. **上传后有证**:回读分支 tip sha 与本次提交 sha 一致,并抽查文件,才允许报成功;
6. **可机检**:契约校验器 + 离线回归测试(不联网也能跑)。

## 成功判据

- `-DryRun` 能在不联网的情况下列出将上传的文件、体积、目标前缀;
- `-SelfTest` 通过(中文转义正确);
- 真上传后 `COMMIT=<sha>` 与远端 `GET /commits/{branch}` 的 sha 一致;
- 疑似密钥文件被拦下并给出 `SECRET_SUSPECTED`;
- 校验器与两个测试脚本全绿。

## 非目标(不做)

- 不建仓库、不改可见性、不删远端文件、不做分支/PR 流程;
- 不替代 git(读历史、合并、变基、多分支并行仍用 git);
- 不保存凭据(token 只在内存里,不落盘不打印);
- 不保证"内容正确",只保证"提交落地且可回读"。
