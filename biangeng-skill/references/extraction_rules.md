# 预算数据提取原则

对比生成变更表的前提，是把「施工图预算（原设计）」和「结算（变更后）」两套预算，
各自**完整、可比、可校验**地归集成一张分部/子目清单。

## 一、四条铁律
1. **金额要全**：提取的所有子目金额之和 = 上级分部金额 = 该部分合计 = 全表合计，允许 ±1 元误差。
2. **子项要全**：不得遗漏任何有金额的细目；确实无法归入某子目的金额，单列一行并注明。
3. **逐项可校验**：每一项都与上级节点做加总校验，差额必须为 0（或说明原因）。
4. **两套口径可比**：原设计与结算必须归集到**同一套分部/子目名**，才能逐行做增减。

## 二、表格隐含层级
`项 → 目 → 节 → 细目 → 清单子目号`。查找节点时对「工程或费用名称」列做模糊包含匹配。
两套预算的编码体系可能不同（如结算用 `102010201`，施工图用 `202-2-1-2`），
**以名称为主、编码为辅**做对应。

## 三、标准输出表头（中间归集表）
`名称 | 单位 | 技术经济指标 | 工程量 | 总金额`
- 「项」行加粗，单位/工程量/指标留空，金额为下级合计。
- 技术经济指标 = 总金额 ÷ 工程量（保留两位小数）；工程量为 0 或空时留 `—`。

## 四、按分部提取规则
- **临时工程**：取「临时供电及电信设施」等。
- **路基工程**：清理/挖除旧路面、挖除水泥混凝土面层、挖除基层底基层、挖土方、挖石方、
  路基填方（利用土方/借土填筑）、边沟/排水工程、挡土墙。
- **路面工程**：垫层（无基层时用垫层，二者同存取金额大者，统一命名「路面基层」/「垫层」）、
  面层、路肩。
- **桥梁涵洞工程**：圆管涵按孔径、盖板涵按跨径；结算若只给合计则按合计对比。
- **交叉工程**：平面交叉/十字交叉。
- **交通工程及沿线设施**：交通标志、凸面镜、示警桩、道口桩、交通标线。
  ⚠️ 结算常把多项合并进「交通标志」科目，需回到「建筑安装工程费计算表」按清单子目拆分。
- **专项费用**：施工场地建设费、安全生产费。
- **第三部分**：工程保险费（建安费×费率）。
- **第四部分**：基本预备费（结算常为 0，则整项为变更减少）。
- **隧道工程**：无子项时跳过。

## 五、特殊处理
- **缺数量补全**：节点数量为空但下挂有数量的清单子目行时，取节点金额，用金额最大的下级行的
  单位/数量反算指标。
- **复合单位**：单位含 `/`（如 `m3/m2`、`m/道`）时，选取能同时对上原/后的那个口径
  （如面层用 m²、涵洞用 m 或 道）；两套口径不一致时按金额对比并在备注说明。
- **新增/取消项**：原设计没有、结算新增的，原设计量记 0，全额计变更增加；
  原设计有、结算取消的，变更后记 0，全额计变更减少。

## 六、增减与单价口径
- **增减造价 = 变更后金额 − 原设计金额**（推荐，能如实反映两套单价的差异）。
- 单价列**拆成两列**：原设计单价、变更后单价（各自 = 金额 ÷ 数量）；无对应值填 `—`。
- 不用「单一单价 × 增减量」，因为两套预算的定额/组价通常不同。

## 七、校验输出
逐项加总并与上级节点比对，格式：
`路基工程 2798428 = 2798428 ✅`；不等时注明差额与可能遗漏的节点。
全表：`原设计 4910278 | 变更后 4728337 | 增减 -181941`。
