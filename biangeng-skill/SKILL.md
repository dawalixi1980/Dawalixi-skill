# 公路工程变更表生成

把「施工图预算（原设计）」与「结算（变更后）」对比后，套用内置模板生成 7 张变更表。

## 前置条件
- Windows + Excel + `pywin32`（生成脚本用 COM 保留模板版式）。
- Python 包：`xlrd`(.xls)、`openpyxl`(.xlsx)、`pypdf`(.pdf)（读取预算文件时用）。
- 已内置母本模板：`assets/模板.xls`（务必用它，不要另找模板）。

## 第 0 步：向用户索取初始数据（每次开始必须先做）
**不要立刻动手，也不要用示例/历史数据顶替。** 先向用户要数据，或让用户把文件放到本地目录并告知路径。
可直接发送下面这段话：

> 生成变更表需要以下材料，请提供，或放到本地某个文件夹后把路径发我：
> 1. 施工图预算（原设计）文件（PDF/Excel）
> 2. 结算（变更后）文件（Excel/PDF）
> 3. 项目基本信息：工程名称、施工单位、监理单位、设计单位、建设单位、编号、图号、桩号、变更类别、变更性质
> 4. 变更原因、变更内容（可先不发，我按数据起草后你再改）
> 模板已内置，无需提供。

- 若用户只给了文件路径：用该路径读取，不要再问一遍。
- 若用户只给了部分：**缺什么问什么**，逐条补齐；单位/编号/桩号等确实无法从文件推出的，
  绝不臆造，必须由用户确认（可给推荐默认值让用户勾选）。
- 若用户说"你自己找"：先在当前工作目录及常见子目录（原设计/结算/施工图/预算）内检索，
  找到候选后向用户确认，而不是默认采用。
- 数据未齐时不要进入第 6 步生成。

## 工作流程

### 1. 读取模板，明确要填的字段
模板 7 张表的工作表名固定：
`工程变更意向审批表（一）`、`工程变更现场勘察与论证表`、`工程变更报告审批表（一）`、
`工程变更报告（意向）审批跟踪表`、`工程变更造价估算表`、`工程变更清单批复表`、`变更工程数量计算表`。
需要的关键字段：工程名称、施工单位、监理单位、设计单位、建设单位、编号、图号、桩号、
变更类别/性质、原工程造价、变更后估价、增减估价、变更原因、变更内容，以及三张数据表的逐行数据。

### 2. 提取两套预算数据
用 `scripts/dump_tables.py` 把预算文件转成文本再阅读：
```
python scripts/dump_tables.py "施工图预算.pdf"  out_原设计.txt
python scripts/dump_tables.py "结算.xlsx"       out_结算.txt
```
提取严格按 **`references/table-extraction-prompt.md`**（三步法：先识别→按需加载规则→最后校验）
与 `references/extraction_rules.md` 执行。**先读这两个文件再动手。**
- 原设计：施工图预算（含「项目清单预算表 / 建筑安装工程费计算表」等），取各分部与细目**单价、数量、金额**。
- 变更后：结算（含「总预算表 / 建筑安装工程费计算表」等）。

### 3. 归集与校验（关键）
按 `references/extraction_rules.md` 的四条铁律归集：
**金额要全、子项要全、子项相加=上级金额（±1元）、两套口径可比**。
逐级做加总校验，任何差额都要查清再往下走。典型层级：
临时工程 / 路基工程 / 路面工程 / 桥梁涵洞工程 / 交叉工程 / 交通工程及沿线设施 / 专项费用，
以及第三部分工程保险费、第四部分基本预备费。

### 4. 逐项对照，算增减
- `增减造价 = 变更后金额 − 原设计金额`。
- 单价拆两列：原设计单价、变更后单价（各自 = 金额 ÷ 数量）。
- 原设计无此项记 0，全额计增加；结算取消记 0，全额计减少。
- 复合单位（`m3/m2`、`m/道`）选取能同时对上原/后的口径；对不上时按金额对比并在备注说明。

### 5. 与人交互确认（务必）
有些数据无法从预算文件推出，**必须问用户**，不要臆造。逐条问、给推荐默认值：
- 施工单位、监理单位、设计单位、建设单位（业主）、编号、图号、桩号。
- 变更类别（一般变更/重大变更）、变更性质（增加/减少/增加与扣减）。
- 变更原因、变更内容的文字（可先按数据差异起草，请用户确认/润色）。
- 表行粒度（按分部细目 / 更细）、单价口径（原设计单价/变更后单价）。
- 涵洞等结算只给合计、无法拆分时的处理方式。
- 拿不准的专项费用取舍（基本预备费是否计、工程保险费费率基数等）。

### 6. 生成
先按 `references/config_schema.md` 写出 `config.json`，再运行：
```
python scripts/build_change_form.py config.json
```
- `template` 建议写 `assets/模板.xls`（脚本会自动相对自身目录解析）。
- `output` 为输出的 .xlsx 路径。
- 脚本自动：复制模板为 xlsx → 填 7 张表 → 造价估算表把「单价」拆成两列 → 数量计算表美化（表头加粗居中、边框、分项行灰底、计算式列合并居中、序号/单位/数量居中）→ 按 `delta/new_cost` 写合计。

### 7. 复算校验
生成后读回文件，核对：
- 造价估算表「增减造价」列合计 = `delta`；「变更后总造价」列合计 = `new_cost`。
- 清单批复表变更前合计 = `orig_cost`；变更后合计 = `new_cost`；增减合计 = `delta`。

## 常见陷阱
- **pywin32 方法必须带括号**：`Range(...).ClearContents()`、`Rows("36:43").Delete()`，
  漏了 `()` 方法不会执行（表现为旧数据残留）。
- **Excel 把 `1-1`、`2-2` 识别成日期**：写「计算式」列前须将该列 `NumberFormat="@"`。
- **合并单元格**：写值要写合并区域的左上角；改写行区前先 `UnMerge` 再写；用 COM 的
  `Rows().Delete()` 能自动调整下方合并区域。
- **Excel COM 偶发返回 None**：`Workbooks.Open` 偶发失败，重试一次即可（或先结束残留 EXCEL 进程）。
- 需要保留母本版式，一律走「复制模板 → 改单元格」，不要用 openpyxl 从零新建。
