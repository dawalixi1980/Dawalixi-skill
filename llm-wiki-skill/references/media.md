# 图片资料归档规范（media）

> 图片要和 Markdown 一样成为**一等资料**：原图不可变、有登记、有引用、**文字层可被检索**。

## 一、为什么图片必须有"文字层"

图片文件本身**不可被 grep / 向量检索**。若只把 PNG 丢进 `raw/`，它等于不存在于知识库里。
所以每张输入图都必须配一张**图文卡** `media/<名>.md`，把图中的
**OCR 文字 + 视觉描述 + 关键洞察**写成文本，图片内容才真正进入知识库。

## 二、两类图片

| 类型 | 来源 | 存放 | 是否可变 |
|---|---|---|---|
| **输入原图** | 截图 / 拍照 / 扫描 / 书本图 / 白板 | `raw/images/` | **不可变**（只读） |
| **生成图** | 由 math-skill 渲染的公式 / 函数图 | 随知识点所在的分类目录 `wiki/<分类>/img/` | 可再生成 |

> 生成图归属哪个知识点，就放进该知识点**所在的目录**（与 Markdown 同处一地，不集中堆到某个全局桶里）。

## 三、命名规范

- 输入原图：`raw/images/YYYYMMDD-<语义slug>.<ext>`，如 `20260914-lagrange-derivation.png`。
- 图文卡：`media/<同名slug>.md`（与图片同 slug，便于配对）。
- 生成图：`wiki/<分类>/img/<页面slug>-<语义>.png`，如 `wiki/微积分/img/导数定义.png`。
- 全小写、连字符分隔（中文语义名也可）。

## 四、图文卡格式：`media/<slug>.md`

```markdown
---
title: <一句话标题>
type: media
source_image: raw/images/<file>
media_kind: screenshot | photo | diagram | whiteboard | book-figure
page: wiki/<分类>/<页面>.md
created: YYYY-MM-DD
tags: [...]
---

# <标题>

![原图](../raw/images/<file>)

> 来源：<哪本书 / 哪一页 / 哪个网站 / 谁拍的>　·　图注：<一句话说明>

## 文字层（OCR）
<图中出现的所有文字。公式一律用 LaTeX 转录，便于检索与复现。>

## 视觉描述
<结构 / 数据流 / 控制流。要求：不看原图也能理解这张图在讲什么。>

## 关键洞察
<这张图最核心的 1–3 点（设计思想 / 约束 / 创新）。>

## 公式复现（如有）
<若有公式，用 math-skill 渲染还原：![复现](<生成图相对路径>)>

## 关联
- 知识点页：[<页面>](../wiki/<分类>/<页面>.md)
- 相关图文卡：[<其他>](./<其他>.md)

## 相关页面
- [← 返回总纲](../index.md)
```

## 五、摄入流程（多模态模型执行）

1. **收图**：把用户给的图片复制进 `raw/images/`，按 `YYYYMMDD-<slug>` 命名（原图之后不再修改）。
2. **读图（多模态）**：对图片做四件事——
   ① OCR 全文；② 公式转录为 LaTeX；③ 写视觉描述（结构/流程）；④ 提炼关键洞察。
3. **写图文卡**：生成 `media/<slug>.md`（用上面的模板）。
4. **归属**：判断这张图属于哪个知识点/页面，把它的引用写进该页正文（见第六节）。
5. **复现公式**：若图含公式，用 math-skill 渲染成 `wiki/<分类>/img/*.png` 并嵌入图文卡，供对照。
6. **登记 & 日志**：在 `raw/源文件清单.md` 增加一行（类型写"图片"）；`log.md` 追加 `## [YYYY-MM-DD] 图片摄入 | <标题>`。

## 六、页面中如何引用图片

- 引用**输入原图**（在知识点页）：
  `![<图注>](../../raw/images/<file>)`（相对路径按页面深度调整）
- 引用**生成图**（在知识点页）：
  `![<图注>](./img/<file>)`
- 若该图有图文卡，正文加一行链接：
  `> 图文卡：[<标题>](../../media/<slug>.md)`

**每张嵌入图必须带**：图注 + 来源（+ 图文卡链接，若有）。

## 七、与「四模式输出」的配合

当图是**书本架构图/流程图**时，图文卡里的「视觉描述」就是模式 1，另在知识点页生成 Mermaid 代码（模式 2），并在卡里写「原图定位」（模式 4）。这样图既被归档，又被转成可渲染、可检索的结构。

## 八、检查清单

- [ ] 每张输入图都有 `raw/images/` 原图 + `media/` 同 slug 图文卡
- [ ] 图文卡含 OCR（公式为 LaTeX）与视觉描述，**可 grep**
- [ ] 图片归属到正确知识点的分类目录
- [ ] 页面引用带图注与来源
- [ ] `raw/源文件清单.md` 与 `log.md` 已更新
