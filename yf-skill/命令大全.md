# yf 命令大全

> 项目归档同步工具（来源隔离的多机协作）。NAS 上项目只有固定 01–08 架构；每台电脑把自己归类好的内容写进 `分类/<本机主机名>/…`，各机互不覆盖。

## 前提

- 命令：终端输入 `yf`（装好后需**新开终端**生效；本机已装到 `C:\Users\Administrator\.yf`）。
- 用之前先设 NAS 根目录（一次即可）：`yf root "Z:\00市政交通所项目档案（存档）"`（建议用 UNC `\\NAS\共享\...`）。
- 在**项目本地文件夹**里操作（`yf run` / `yf go` 默认用当前文件夹）。

## 命令一览

| 命令 | 作用 |
|---|---|
| `yf run [路径]` | 检索 NAS 项目 + 把 01–08 架构补进本地（建立映射） |
| `yf go [路径]` | 同步：本地归类好 → 上传到 NAS 的 `分类/<主机名>/`（未归类则**直接拒绝**） |
| `yf pull [路径]` | 拉取：选【分类 + 来源】，推荐**最后同步时间最新**的来源 |
| `yf find <关键词>` | 搜项目 → 在项目里搜文件名 → 选着拉取（`--into 目标目录`） |
| `yf open [路径]` | **用资源管理器直接打开该项目的 NAS 文件夹** |
| `yf sources [路径]` | 列出某项目各分类下的来源（主机名 / 最后同步时间） |
| `yf whoami` | 看本机来源名（主机名）、IP、会写进哪 |
| `yf list` | 查看本地↔NAS 的映射 |
| `yf root <路径>` | 设置 NAS 归档根目录 |
| `yf setup` | 配置向导（设置 NAS 根目录） |
| `yf help` | 显示帮助 |

## 逐个说明

### `yf run [路径]`
第一次用：按名称相似度在 NAS 归档里检索项目文件夹 → 确认后写入映射 → 把 **01–08 八个顶层文件夹**补进本地当前文件夹。
第二次起：按本地路径精确匹配，直接复用映射。

```bat
cd 你的项目文件夹
yf run
```

### `yf go [路径]`
把本地各分类里的文件，上传到 NAS 对应分类下的 **本机来源层**：
`本地 05初步设计\图纸1` → `NAS 05初步设计\<主机名>\图纸1`

- **未归类拒绝**：本地根目录出现 01–08 之外的文件/文件夹 → 直接拒绝，提示先整理。
- **同机可覆盖自己**；别的电脑的来源文件夹**绝不改动**。
- 有**进度条**；只传新增/改动的文件。
- 日志写到 NAS `_同步日志\<主机名>.log` 和本地 `项目日志.txt`（含 时间 / 主机名 / IP / 分类 / 文件数）。

```bat
yf go
```

### `yf pull [路径]`
其他人（或多台电脑）传上来的内容，按【分类 + 来源(主机名)】拉到本地。
默认推荐**最后同步时间最新**的来源；拉来的来源会写 `.yfsource` 标记，`yf go` 不会再把它传回去。

```bat
yf pull
```

### `yf find <关键词>`  （关键词**不带括号**）
按关键词搜项目和项目内的文件，再选着拉取到本地。
例：`yf find 单改双`。

```bat
yf find 单改双
yf find 单改双 --into D:\临时下载
```

### `yf open [路径]`  ← **直接打开 NAS 文件夹**
用资源管理器打开当前项目对应的 NAS 文件夹（需先 `yf run` 建立映射）。

```bat
yf open
```

### `yf sources [路径]`
列出某项目各分类下有哪些来源、各自最后同步时间。

```bat
yf sources
```

### `yf whoami`
显示本机来源名（= 主机名）、本机 IP，以及同步时会写进 NAS 的位置。

```bat
yf whoami
```

### `yf list` / `yf root <路径>` / `yf setup`
映射查看、设置 NAS 根目录、配置向导。

```bat
yf list
yf root "Z:\00市政交通所项目档案（存档）"
yf setup
```

## 典型流程

```bat
:: 第一次（在项目文件夹）
yf root "Z:\00市政交通所项目档案（存档）"   :: 只需一次
yf run                                       :: 检索项目 + 补 01-08 架构
:: 把文件归类进 01-08 …
yf go                                        :: 上传（带进度条）

:: 别的电脑拉取
yf run                                       :: 先建立同一项目的映射
yf pull                                      :: 选分类 + 来源（推荐最新）
```

## 常见问题

| 现象 | 处理 |
|---|---|
| `yf` 不是内部或外部命令 | 新开终端；仍不行就用全路径 `%USERPROFILE%\.yf\yf.cmd`，或注销/重登刷新 PATH |
| `go` 提示拒绝 | 本地根目录有 01–08 之外的东西，先归类 |
| `go` 没反应/卡 | 现在有进度条；大项目先扫描再上传属正常 |
| 拉来的东西又被传上去 | 不会——拉取来源有 `.yfsource` 标记，`go` 自动跳过 |
| 需要分支/历史 | 本工具不做，用 git |

## 说明

- 来源名 = **主机名**（换电脑自动识别，无需配置）。
- 架构 = **只要 8 个顶层**（01–08），不建"过程文件/成果文件"子层。
- `nas_root` 建议用 UNC；别写盘符（换机会废）。
