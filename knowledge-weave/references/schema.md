# The Vault · 结构规则

## 四件产物

| # | 文件 | 角色 |
|:--:|---|---|
| 1 | `00-问题库.md` | **问题库**：以我的问题为起点，链式（Q1→Q2→Q3） |
| 2 | `01-知识清单.md` | **知识清单**：所有知识原点（索引，`[[ ]]` 指向详细知识） |
| 3 | `02-详细知识/<名>.md` | **详细知识**：每个原点一页；相互 `[[双向链接]]` |
| 4 | `03-大纲骨架.md` | **大纲 / 网络骨架**：主观主干 ＋ 教材目录 |

## 规则

- **导航靠 `[[双向链接]]`，不靠目录层级。**
- 每个**问题页**记：**长出 N 个知识点** ＋ 链接。
- 每个**知识原点**标状态：`主观 / 已验证 / 待证`。
- 未连的原点 = 孤岛，视为未完成。

## 目录

```
00-问题库.md
01-知识清单.md
03-大纲骨架.md
02-详细知识/
   └─ <知识点>.md
```
> 编号只为排序；**关系由链接决定，不由文件夹决定**。
