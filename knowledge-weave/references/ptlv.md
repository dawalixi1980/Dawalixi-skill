# The Loop · 四拍详解

> Push 推问 → Top 顶 → Link 连 → Verify 验

## Push · 推问

- 提出一个问题：**你问，或我问，都行**；但必须**建立在你已理解的基础**上。
- **从"现象"出发，不从章节。**（例：为什么 $\int_a^b f = F(b)-F(a)$？）
- **链式**：一个问题衍生下一个（约 3–4 问），知识点随之展开。
- 够不着 → 把问题**往下拆**。

## Top · 顶

> 用你**已经会**的东西，去顶这个新问题。

| 结果 | 含义 | 下一步 |
|---|---|---|
| **顶得动** | 已会知识够用 | 过，不用学 |
| **顶不动 / 矛盾** | 已会知识不够用 | **找到了边界 → 这里才需要新知识** |

- 顶不动 = 变构说的「认知干扰」——正因为卡住，才想学。

## Link · 连

- 每个新知识点（**知识原点**）用 `[[双向链接]]` 挂到相关原点。
- 知识点之间**相互印证**（也 `[[ ]]`）。
- 问题页记：**长出 N 个知识点** ＋ 链接。

## Verify · 验

- 用 **Learn** 骨架（**主观主干 ＋ 教材目录**）**查漏**。
- 用**现实锚点（物）**核验：现象 / 物理实例（**必要时**才加）。
- 顶不动 / 待证 → 记入缺口。

## The Weave · 链式推进

```
Q1（现象）
  └─ 顶不动 → 引出 Q2
        └─ 顶不动 → 引出 Q3
              └─ …（约 3–4 问）
     → 知识原点铺开 → 织成网
```
