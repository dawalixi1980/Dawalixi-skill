# 模板（四件产物）

## 1. `00-问题库.md`

```markdown
# 问题库

> 以「我的问题」为起点，链式推进。

- **Q1**：<现象 / 疑问>
  - 我的理解（可能错）：<...>
  - 顶：会 <...>；顶不动 <...>
  - 长出：[[知识点A]] ｜ [[知识点B]] ｜ [[知识点C]]
- **Q2**（由 Q1 衍生）：<...>
  - …
```

## 2. `01-知识清单.md`

```markdown
# 知识清单

| 知识原点 | 来自 | 状态 |
|---|---|---|
| [[知识点A]] | Q1 | 主观 |
| [[知识点B]] | Q1 | 已验证 |
```

## 3. `02-详细知识/<知识点>.md`

```markdown
# <知识点>

> 状态：主观 / 已验证 / 待证

- **一句话**：<它研究什么>
- **通俗解释**：<大白话>
- **公式 / 图**：![...](./img/....png)
- **相互印证**：[[相关知识点1]] ⇄ [[相关知识点2]]
- **来自问题**：[[Q1]]
- **出处 / 佐证**：《...》 <乐享链接>（日期）
```
