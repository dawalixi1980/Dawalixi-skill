# Construction Drawing Review

## Overview

系统校审施工图的专业审查提示词，输出规范化的审图意见表。提供一份可复用的完整审查提示词模板（见 `assets/施工图审查提示词.txt`）。

## Workflow

1. 定位图纸目录：确认用户给出的施工图所在目录，判断专业构成（道路、交通、排水、给水、通信、绿化等）。
2. 读取并应用审查提示词：将 `assets/施工图审查提示词.txt` 的完整内容作为审查依据。
3. 用户有需要时，直接输出该提示词文件内容（读原文件后原样给出，勿改写）。
4. 用户给图纸时，按提示词的"重点检查项"逐项自动开展审查。
5. 按提示词"三、输出格式"生成校审意见表格，并给出汇总。

## Output

- 校审意见表格（序号 / 专业册 / 图号 / 图名 / 问题类型 / 问题描述 / 建议修改意见 / 强度）。
- 问题数量统计与关键必改项清单。

## Resources

- `assets/施工图审查提示词.txt`：完整、可复用的施工图审查提示词模板（用户需复制或用做审查依据时读取）。
